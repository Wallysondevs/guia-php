PHP Operadores Lógicos

Uma comparação responde uma pergunta só: "a idade é maior que 18?". Na vida real, as perguntas são compostas: "é maior de idade e tem ingresso?", "pagou com Pix ou com cartão?", "não está logado?". Os operadores lógicos juntam várias respostas true/false numa só. Eles são a base de toda decisão que você vai escrever com if.

Você vai aprender
  • Os três operadores principais: && (e), || (ou) e ! (não), com as tabelas-verdade.
  • O xor (ou exclusivo): "um ou outro, mas não os dois".
  • As palavras and e or, e a armadilha delas com o = (com a demonstração real).
  • O curto-circuito: por que a ordem das perguntas evita um erro fatal.
  • O que acontece quando os valores não são booleanos (no PHP, o resultado é sempre true ou false).

Antes, é bom ter visto Booleanos (o que vale true e false) e Comparação (de onde vêm os true/false). Os resultados aparecem com o var_dump, que mostra bool(true) ou bool(false).

A ideia: as regras da portaria

A Ana trabalha na portaria de um show. Ela recebeu três regras:

  • "Entra quem tem 18 anos e tem ingresso." As duas coisas precisam ser verdade.
  • "Ganha meia-entrada quem é estudante ou tem 60 anos ou mais." Basta uma.
  • "Quem não tem pulseira vai para a fila." Inverte a resposta.

Esses três "conectivos", e, ou e não, são os operadores lógicos. No PHP, eles se escrevem &&, || e !. O resultado de cada um é sempre true (verdadeiro) ou false (falso).

O ! (ponto de exclamação) vem antes de um valor e o inverte: true vira false e vice-versa.

var_dump(!$logado);
var_dump(!true);
var_dump(!0);

"Não está logado?" Como $logado é false, a resposta é true.

O ! funciona com qualquer valor. O PHP primeiro converte o valor para booleano (0 vale false, veja Booleanos) e depois inverte.
!"Ana"
Um texto não vazio vale true; invertido, false.

Duas negações se anulam. O efeito é converter para booleano: !!"Ana" é o mesmo que (bool) "Ana".
O ! gruda só no vizinho

!$nome == "Bia" não é "o nome não é Bia". O PHP entende (!$nome) == "Bia". Para negar uma comparação, use $nome !== "Bia" ou !($nome == "Bia"). A aula Precedência mostra a saída real.

Misturando && e ||

Quando os dois aparecem na mesma linha, o && é feito primeiro (como a multiplicação antes da soma). A regra da portaria mudou: "convidado VIP entra; os outros precisam ter 18 anos e ingresso". Veja a diferença que os parênteses fazem para um VIP de 16 anos sem ingresso:

<?php
$convidadoVip = true;
$idade = 16;
$temIngresso = false;

var_dump($convidadoVip || $idade >= 18 && $temIngresso);
var_dump(($convidadoVip || $idade >= 18) && $temIngresso);

$ php vip.php
bool(true)
bool(false)
$convidadoVip || $idade >= 18 && $temIngresso
O PHP lê $convidadoVip || ($idade >= 18 && $temIngresso): "é VIP, ou é maior e tem ingresso". VIP entra: true.
($convidadoVip || $idade >= 18) && $temIngresso
Outra regra: "(é VIP ou maior) e tem ingresso". Sem ingresso, ninguém entra: false.

As duas regras fazem sentido; só você sabe qual é a certa. Por isso, sempre que misturar && e ||, escreva os parênteses, mesmo quando a ordem natural já é a que você quer: $convidadoVip || ($idade >= 18 && $temIngresso).

xor: "ou exclusivo" (um ou outro, não os dois)

xor vem do inglês exclusive or, "ou exclusivo". Ele dá true quando exatamente um dos lados é true. Se os dois forem iguais (ambos true ou ambos false), dá false.

<?php
var_dump(true xor false);
var_dump(false xor true);
var_dump(true xor true);
var_dump(false xor false);
$pix = true;
$cartao = true;
var_dump($pix xor $cartao);
$ok = $pix xor $cartao;
var_dump($ok);
$ok = ($pix xor $cartao);
var_dump($ok);
var_dump($pix != $cartao);

Mas repare na 6ª linha da saída: $ok = $pix xor $cartao; guardou true, embora a resposta certa seja false. O xor só existe em forma de palavra, e as palavras lógicas têm a armadilha da próxima seção. Com parênteses (7ª linha), funciona. Para booleanos, $pix != $cartao dá o mesmo resultado que o xor, sem armadilha.

and e or: as palavras e a armadilha do =

O PHP também aceita as palavras and ("e") e or ("ou"), em letras minúsculas ou maiúsculas (AND, Or…). A conta é a mesma do && e do ||. A diferença está na prioridade: as palavras ficam no fim da tabela de precedência, abaixo do =. Veja o que isso causa:

$temIngresso = true;
$maiorDeIdade = false;

$podeEntrar = $temIngresso and $maiorDeIdade;
var_dump($podeEntrar);

$podeEntrar = $temIngresso && $maiorDeIdade;
var_dump($podeEntrar);

$podeEntrar = ($temIngresso and $maiorDeIdade);
var_dump($podeEntrar);

Então por que and e or existem?

Para um estilo antigo, que você ainda vai ver em tutoriais e código legado: "faça isto ou pare o programa".

<?php
$arquivo = fopen("nao-existe.txt", "r") or die("Não consegui abrir o arquivo.\n");
echo "Arquivo aberto!\n";

$ php die.php

Warning: fopen(nao-existe.txt): Failed to open stream: No such file or directory in /home/ana/site/die.php on line 2
Não consegui abrir o arquivo.

Aqui a prioridade baixa do or é proposital: primeiro $arquivo = fopen(…) (abrir o arquivo, veja Ler e Escrever Arquivos); se o resultado for false, o or roda o die, que mostra a mensagem e encerra o programa. Hoje, o jeito recomendado de tratar falhas é com if ou exceções.

Regra prática

Use sempre &&, || e !. Deixe and e or para ler código antigo. Para xor, que só existe como palavra, use parênteses: $ok = ($a xor $b);.

Curto-circuito: o PHP para assim que sabe a resposta

Pense no &&: se o lado esquerdo já é false, o resultado vai ser false, não importa o lado direito. Então o PHP nem olha o lado direito. Com o ||, se o lado esquerdo já é true, o resultado é true, e o lado direito é pulado. Isso se chama curto-circuito (ou avaliação preguiçosa).

Dá para ver o curto-circuito com o print, que mostra um texto (veja echo e print) e pode ser usado no meio de uma expressão:

<?php
var_dump(false && print("lado direito do &&\n"));
var_dump(true && print("lado direito do &&\n"));
var_dump(true || print("lado direito do ||\n"));
var_dump(false || print("lado direito do ||\n"));

Para que serve: perguntar primeiro se é seguro

O curto-circuito permite colocar uma pergunta de proteção antes de uma conta perigosa. A Ana quer saber se o pedido é "grande" (mais de R$ 10 por item, em média), mas o carrinho pode estar vazio, e dividir por zero é um erro fatal:

<?php
$itens = 0;
$total = 50;

var_dump($itens > 0 && $total / $itens > 10);
var_dump($total / $itens > 10 && $itens > 0);

$ php divisao.php
bool(false)

Fatal error: Uncaught DivisionByZeroError: Division by zero in /home/ana/site/divisao.php:6
Stack trace:
#0 {main}
  thrown in /home/ana/site/divisao.php on line 6
$itens > 0 && $total / $itens > 10
A proteção vem primeiro. $itens > 0 é false, então a divisão nunca acontece. Resultado: false, sem erro.
$total / $itens > 10 && $itens > 0
As mesmas perguntas, na ordem errada. A divisão por zero acontece antes da proteção, e o programa para com DivisionByZeroError ("erro de divisão por zero").

O mesmo truque evita avisos com chaves que podem não existir num array:

<?php
$aluna = ["nome" => "Ana"];

bool(false)

Com o isset ("está definido?") primeiro, a chave só é lida se existir. Na ordem inversa, o PHP lê a chave antes e avisa. (Para dar um valor padrão a uma chave que pode faltar, existe também o ??.)

Ordem das perguntas

Num &&, coloque à esquerda a pergunta que protege (existe? é maior que zero? não é null?) e à direita a que usa o valor. Bônus: se a pergunta da esquerda for mais rápida, o programa também fica mais rápido.

Com valores que não são booleanos

Os operadores lógicos aceitam qualquer valor: o PHP converte cada lado para booleano (as regras estão em Booleanos: 0, "", "0", null e [] valem false; o resto, true). E o resultado é sempre true ou false:

<?php
var_dump("Ana" && 0);
var_dump("Ana" || 0);
$nome = "";
var_dump($nome || "visitante");
var_dump($nome ?: "visitante");

$ php tipos.php

bool(true)
bool(true)
string(9) "visitante"
Para quem vem do JavaScript

No JavaScript, nome || "visitante" devolve "visitante". No PHP, o || devolve bool(true), nunca o valor. Para "este valor ou um padrão", o PHP tem o ?: (quando o valor é vazio) e o ?? (quando é null ou não existe).

Resumo

  • && (e): true só se os dois forem true. || (ou): true se pelo menos um for. ! (não): inverte.
  • xor: true se exatamente um for true. Use com parênteses.
  • O && vem antes do ||. Ao misturar os dois, escreva os parênteses.
  • and/or fazem a mesma conta, mas ficam abaixo do =: $x = true and false guarda true. Prefira &&/||.
  • Curto-circuito: o PHP para assim que sabe a resposta. Coloque a pergunta de proteção à esquerda.
  • O resultado é sempre bool, mesmo com textos e números. Um & ou | sozinho é outra coisa (bits).
