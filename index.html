Tutorial PHP

Aprenda PHP do zero, como numa escola: cada linha de código é explicada parte por parte, você vê exatamente o que aparece na tela e pratica num editor aqui mesmo no navegador. E não é uma imitação: o editor roda o PHP 8.5 de verdade, o mesmo programa que funciona nos servidores. Todas as saídas e mensagens de erro do guia foram conferidas num PHP real. Vale para Linux, Windows e macOS.

Experimente agora

A caixa abaixo é o editor Experimente do guia. Ela tem um programa PHP completo, de duas linhas, pronto para rodar. Clique em Rodar. Na primeira vez, o navegador baixa o PHP (alguns segundos); depois, cada execução é instantânea. Nada do que você fizer aqui mexe no seu computador.

Missão: clique em Rodar e veja o Olá, mundo! aparecer. Depois troque o texto entre as aspas por Estou aprendendo PHP! e rode de novo. Cuidado para não apagar as aspas " nem o ; do fim da linha.

<?php
echo "Olá, mundo!";

<?php
echo "Estou aprendendo PHP!";

O que aconteceu: a primeira linha, <?php, avisa "daqui para frente é código PHP". A segunda linha é a única que faz alguma coisa: echo (em inglês, "ecoar") manda o PHP escrever o texto que está entre as aspas. O ; no fim termina a instrução, como o ponto final de uma frase. Na aula Olá, Mundo você vai entender cada pedaço com calma.

Se você apagou uma aspa ou o ponto e vírgula, viu uma mensagem em inglês começando com Parse error. Não se assuste: é o PHP dizendo em que linha ele se perdeu. A aula Lendo Erros do PHP ensina a ler essas mensagens.

O PHP que faz páginas da web

O programa acima escreveu um texto simples, como num terminal. Mas o PHP nasceu para outra coisa: montar páginas da web. Na caixa abaixo, o código é tratado como uma página de um site. Repare que ele é quase todo HTML (a linguagem das páginas), com pedacinhos de PHP no meio, entre <?= e ?>. Clique em Rodar e veja as duas abas: Resultado (a página como o navegador mostra) e Código-fonte HTML (o que o PHP de fato enviou).

Missão: faça a página dizer Bem-vinda, Bruno! (troque o nome) e calcule 3 + 4 no lugar de 2 + 3. Depois abra a aba Código-fonte HTML: o <?= sumiu, e no lugar dele está só o resultado.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Lojinha da Ana</title>
</head>
<body>
  <h1>Bem-vinda, <?= "Ana" ?>!</h1>
  <p>Hoje temos <?= 2 + 3 ?> produtos na vitrine.</p>
</body>
</html>

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Lojinha da Ana</title>
</head>
<body>
  <h1>Bem-vinda, <?= "Bruno" ?>!</h1>
  <p>Hoje temos <?= 3 + 4 ?> produtos na vitrine.</p>
</body>
</html>

Esse é o truque do PHP: ele roda no servidor, calcula o que precisa (aqui, 3 + 4) e entrega ao navegador um HTML comum, já pronto. Quem visita o site nunca vê o código PHP, só o resultado. Num site de verdade, no lugar de "Ana" estaria o nome de quem fez login, e no lugar de 2 + 3, a contagem dos produtos guardados num banco de dados. A aula Como o PHP Funciona mostra esse caminho passo a passo, e a aula PHP Dentro do HTML ensina a misturar os dois.

O que é este guia

O PHP é a linguagem que funciona "por trás" da maior parte dos sites da internet: segundo a W3Techs, ela aparece em 69,4% dos sites cuja linguagem do servidor é conhecida (levantamento de 16 de outubro de 2026). O WordPress, o Moodle, a Wikipédia e incontáveis lojas virtuais são feitos em PHP. Quem aprende PHP consegue:

  • escrever programas que fazem contas, tomam decisões e repetem tarefas;
  • criar páginas que mudam sozinhas: mostram o nome de quem entrou, a lista de produtos do dia, o resultado de uma busca;
  • receber formulários (contato, cadastro, login), guardar dados num banco e mostrá-los de volta, com segurança;
  • entender e modificar sistemas como WordPress e Laravel, e criar APIs que aplicativos de celular consomem.

O guia é para quem nunca programou. Ele começa do zero absoluto (o que é um programa? o que é um servidor?) e vai até o PHP moderno: orientação a objetos, Composer, testes, enums, property hooks e o operador pipe |> do PHP 8.5. A aula O que é PHP conta a história da linguagem e mostra onde ela é usada.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, você entende o problema que ele resolve, com uma comparação do dia a dia.
  2. Anatomia. Cada pedaço de uma linha nova é separado e explicado: o que é palavra do PHP, o que é nome escolhido por você, para que serve cada símbolo.
  3. A saída real. Você vê exatamente o que aparece na tela, com etiquetas laranja apontando o que importa. Toda saída foi produzida por um PHP 8.5 de verdade.
  4. Experimente. Pelo menos duas caixas por aula para você mudar o código e rodar, muitas com uma missão e um botão para ver a solução. As caixas rodam o PHP real, então os erros que você vir são os mesmos que veria no seu computador.
  5. Várias formas de fazer. Quase sempre há mais de um caminho, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro, a mensagem real do PHP, o que ela quer dizer e como consertar.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de uma linha

Esta é a linha que você rodou lá em cima. Veja como as aulas desmontam uma linha de código:

echo "Olá, mundo!";
echo
Uma palavra do PHP (em inglês, "ecoar"): escreve na saída o que vier depois dela. Num terminal, a saída é a tela; num site, é a página que vai para o navegador.
"Olá, mundo!"
O texto a escrever. As aspas marcam onde o texto começa e termina; elas não aparecem no resultado. Em programação, um texto assim se chama string.
;
O ponto e vírgula termina a instrução, como o ponto final de uma frase. Esquecer o ; é o erro número um de quem começa.

Exemplo: o terminal

Além do editor, as aulas mostram o terminal da máquina fictícia do guia: um computador chamado notebook, da usuária ana, com o PHP 8.5 instalado. Ali, o comando php roda um arquivo de código e mostra o que ele escreve:

$ cd site
$ cat ola.php                      « mostra o conteúdo do arquivo
<?php
echo "Olá, mundo!\n";
$ php ola.php                      « o PHP lê o arquivo e executa
Olá, mundo!
$ echo $?
0                                  « código de saída 0: terminou sem erro

O \n dentro das aspas é uma quebra de linha: sem ele, o prompt do terminal ficaria grudado no fim do texto. No editor do guia isso não faz diferença, mas no terminal faz; a aula echo e print explica.

E o mesmo arquivo pode virar uma página da web. O PHP tem um servidor embutido, o php -S, que transforma uma pasta do seu computador num site de teste. Com ele rodando, o navegador (ou o comando curl, um "navegador de terminal") pede a página e recebe o resultado:

$ curl localhost:8000/ola.php       « pede a página ao servidor php -S
Olá, mundo!

A aula O Servidor Embutido mostra cada passo, e a aula O Editor do Guia ensina a usar as caixas Experimente nos dois modos: o de terminal e o de página web.

Versão de referência: PHP 8.5

As saídas do terminal foram conferidas no PHP 8.5.8, num Linux em português do Brasil. O editor do navegador roda o PHP 8.5.10, a mesma versão compilada para WebAssembly (o formato que os navegadores executam); as diferenças entre as duas são só correções de falhas e quase nunca mudam uma saída. Quase tudo do Nível 1 funciona igual no PHP 8.2, 8.3 e 8.4; quando um recurso é novo, a aula avisa com o selo de versão. A aula Versões do PHP explica as versões e até quando cada uma recebe correções.
