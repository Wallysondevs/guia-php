PHP Projeto Formulário de Contato

A lojinha da Ana vende cestas de café da manhã e quer receber mensagens dos clientes pelo site. Neste projeto você constrói o formulário de contato completo: ele confere cada campo, mostra o erro ao lado do campo certo, não apaga o que a pessoa digitou, guarda as mensagens num arquivo e não grava a mesma mensagem duas vezes quando alguém aperta F5.

Você vai aprender
  • Guardar os campos num array $dados e os erros num array $erros com o nome do campo como chave.
  • Validar nome, e-mail (filter_var), assunto e mensagem (mb_strlen), e mostrar cada erro no lugar certo.
  • Devolver os valores para input, select e textarea com segurança.
  • Salvar cada mensagem como uma linha de CSV com fputcsv (e a versão em JSON).
  • O padrão Post/Redirect/Get: por que o F5 duplica envios e como o header('Location: …') resolve.
  • Listar as mensagens recebidas numa tabela, sem deixar uma mensagem maliciosa estragar a página.

  2. Etapa 2 · Validar cada campo

    Agora as regras. Cada erro entra em $erros com o nome do campo como chave: $erros['email'] = '…'. Assim, na hora de mostrar, sabemos exatamente ao lado de qual campo cada mensagem vai.

    $erros = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (mb_strlen($dados['nome']) < 2) {
        $erros['nome'] = 'Escreva o seu nome.';
    }
    if (filter_var($dados['email'], FILTER_VALIDATE_EMAIL) === false) {
        $erros['email'] = 'Esse e-mail não parece válido.';
    }
    if (!array_key_exists($dados['assunto'], $assuntos)) {
        $erros['assunto'] = 'Escolha um assunto da lista.';
    }
    $tamanho = mb_strlen($dados['mensagem']);
    if ($tamanho < 10 || $tamanho > 1000) {
        $erros['mensagem'] = "A mensagem precisa ter entre 10 e 1000 caracteres (tem $tamanho).";
    }
}
    RegraPor quê
    mb_strlen($dados['nome']) < 2Conta as letras do nome. O strlen comum conta bytes, e cada letra acentuada vale 2 bytes em UTF-8: strlen('Zé') é 3. Para texto em português, use as funções mb_ (veja Acentos e mbstring).
    filter_var($email, FILTER_VALIDATE_EMAIL)"Filtrar a variável como e-mail": devolve o próprio e-mail se ele tiver um formato válido, ou false. No laboratório, ana@exemplo.com passou; ana@exemplo, ana.exemplo.com e ana@localhost deram false. Formato válido não quer dizer que o e-mail existe; só que parece um e-mail.
    === falseCompara com false de forma estrita, porque o retorno bom é um texto.
    array_key_exists($dados['assunto'], $assuntos)O assunto tem que ser uma das chaves da lista. Qualquer pessoa pode enviar assunto=spam pelo curl.
    "… (tem $tamanho)."Aspas duplas trocam $tamanho pelo valor (veja Interpolação). Dizer quanto falta ajuda a pessoa a corrigir.

  3. Etapa 3 · Salvar a mensagem num arquivo CSV

    Quando não há erros, a mensagem vai para o fim do arquivo mensagens.csv, uma linha por mensagem. CSV ("valores separados por vírgula") é o formato de planilha mais simples que existe: abre no LibreOffice Calc e no Excel.

    <?php
date_default_timezone_set('America/Sao_Paulo');
...
$erros = [];
$enviado = false;

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // ... as quatro validações da etapa 2 ...

    if (!$erros) {
        $linha = [date('Y-m-d H:i:s'), $dados['nome'], $dados['email'], $dados['assunto'], $dados['mensagem']];
        $arquivo = fopen(__DIR__ . '/mensagens.csv', 'a');
        fputcsv($arquivo, $linha, ',', '"', '');
        fclose($arquivo);
        $enviado = true;
    }
}
    date_default_timezone_set(…)
    Diz ao PHP o fuso horário. Sem isso (e sem configurar o php.ini), o PHP usa UTC: no laboratório, date_default_timezone_get() respondeu UTC, e as mensagens sairiam com 3 horas a mais.
    fopen(…, 'a')
    Abre o arquivo no modo 'a' (append, "acrescentar"): escreve no fim, sem apagar o que já existe, e cria o arquivo se ele não existir.
    __DIR__ . '/mensagens.csv'
    __DIR__ é a pasta do próprio index.php. Usar o caminho completo evita surpresas quando o PHP roda a partir de outra pasta.
    fputcsv($arquivo, $linha, ',', '"', '')
    Escreve o array como uma linha CSV, cuidando sozinho das vírgulas e aspas dentro do texto. Os três últimos argumentos são o separador, a aspa e o caractere de escape; o escape vazio '' é o recomendado e, no PHP 8.4+, precisa ser informado (veja "Quando dá errado").
    fclose($arquivo)
    Fecha o arquivo e garante que tudo foi gravado.

  6. Etapa 6 (alternativa) · Salvar em JSON em vez de CSV

    CSV é ótimo para abrir numa planilha. Se as mensagens forem lidas por outro programa (uma API, um painel em JavaScript), JSON costuma ser mais prático: cada mensagem guarda os nomes dos campos. A troca fica toda numa função:

    function salvarMensagem(array $mensagem): void
{
    $caminho = __DIR__ . '/mensagens.json';

    $lista = [];
    if (file_exists($caminho)) {
        $lista = json_decode(file_get_contents($caminho), true) ?? [];
    }

    $lista[] = $mensagem;

    file_put_contents(
        $caminho,
        json_encode($lista, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE),
        LOCK_EX
    );
}

    E, no lugar das quatro linhas do CSV, uma só:

            salvarMensagem(['quando' => date('Y-m-d H:i:s')] + $dados);
    TrechoO que faz
    json_decode(…, true)Lê o JSON como array associativo (o true). Se o arquivo estiver vazio ou estragado, devolve null, e o ?? [] recomeça com uma lista vazia.
    $lista[] = $mensagemAcrescenta a nova mensagem no fim da lista.
    JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODEArquivo bonito, com recuo, e acentos escritos como acentos (sem a opção, sábado viraria sábado).
    LOCK_EXTrava o arquivo enquanto escreve, para dois envios ao mesmo tempo não se atropelarem na escrita.
    ['quando' => …] + $dadosO + junta dois arrays associativos: a data primeiro, depois os quatro campos.

O que significa: "não posso mudar os cabeçalhos: eles já foram enviados (a saída começou em teste.php:1)". Os cabeçalhos vão antes do conteúdo; a linha em branco já era conteúdo, então o PHP já tinha mandado os cabeçalhos (com 200 OK), e o redirecionamento não aconteceu. Como consertar: o <?php tem que ser a primeiríssima coisa do arquivo, e nenhum echo ou HTML pode vir antes do header(). A mensagem diz exatamente o arquivo e a linha culpados. (Algumas instalações têm output_buffering ligado no php.ini e escondem esse erro; não conte com isso.)

Deprecated: fputcsv(): the $escape parameter must be provided as its default value will change

Aparece no PHP 8.4+ quando você chama fputcsv($arquivo, $linha) só com dois argumentos (o mesmo vale para fgetcsv). O que significa: "informe o parâmetro $escape, porque o valor padrão dele vai mudar". Como consertar: passe os três: fputcsv($arquivo, $linha, ',', '"', ''). O escape vazio segue o padrão CSV de verdade (aspas dobradas).

Resumo

  • $dados guarda os campos (com trim e ??); $erros guarda as mensagens com o nome do campo como chave.
  • Valide no servidor: mb_strlen para tamanhos, filter_var(…, FILTER_VALIDATE_EMAIL) para e-mail, lista de valores permitidos para o select.
  • Todo valor devolvido para a página passa por htmlspecialchars (aqui, a função e()): em value, dentro do textarea e na listagem.
  • fputcsv($f, $linha, ',', '"', '') escreve CSV corretamente; JSON com json_encode(…, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE) e LOCK_EX.
  • Post/Redirect/Get: depois de salvar, header('Location: …', true, 303); exit;. Nada pode ser impresso antes do header().
