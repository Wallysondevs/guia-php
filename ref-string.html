PHP Funções de String

As funções de texto que você vai usar no dia a dia, agrupadas pelo que fazem, com as versões mb_* para textos com acento. Cada linha tem a assinatura, uma explicação curta, um exemplo e o resultado real, conferido no PHP 8.5 da máquina da Ana. Para aprender com calma, veja Strings, Funções de String, Acentos e mbstring e printf e sprintf.

Como ler as tabelas
  • Os exemplos usam estas variáveis (cada exemplo começa do zero): 
    <?php
$texto   = "banana";
$nome    = "  Ana Souza  ";
$palavra = "Ação";
  • A assinatura mostra os parâmetros e, depois dos dois-pontos, o tipo do resultado. Parâmetros com = valor são opcionais. int|false = devolve um número ou false.
  • Os resultados estão escritos como código PHP: 'nana' é um texto; true/false, booleanos; ['ab', 'cd'], um array. Textos com quebra de linha aparecem entre aspas duplas com \n; bytes soltos (um acento cortado ao meio) aparecem como "\xA7".
  • Os índices começam em 0: em "banana", o b é a posição 0. Nenhuma função muda o texto original; todas devolvem um texto novo.

Antes de tudo: bytes × letras

O PHP guarda textos em UTF-8, em que letras com acento ocupam 2 bytes. As funções sem mb_ contam e cortam bytes; as mb_* ("multibyte") contam letras. Com textos em português, a diferença aparece logo:

<?php
$palavra = "Ação";
echo strlen($palavra), " bytes, ", mb_strlen($palavra), " letras\n";
echo strtoupper($palavra), " × ", mb_strtoupper($palavra), "\n";
echo substr($palavra, 0, 2), " × ", mb_substr($palavra, 0, 2), "\n";

$ php bytes.php
6 bytes, 4 letras
AçãO × AÇÃO
A� × Aç

O substr cortou o ç no meio (ficou só o primeiro dos seus 2 bytes, que o terminal mostra como �). Regra prática: para contar, cortar, mudar maiúsculas ou completar textos que podem ter acento, use a versão mb_. Para procurar e trocar (str_contains, str_replace), as normais funcionam bem.

A armadilha do strpos

strpos($texto, "b") dá 0 (achou, na posição 0), e 0 conta como falso num if. Escreva if (strpos($texto, "b") !== false), ou simplesmente if (str_contains($texto, "b")).

Qual usar para mostrar dados do visitante?

htmlspecialchars, sempre, no momento de escrever no HTML: ele mantém o texto como o visitante digitou, só que inofensivo. strip_tags apaga partes do texto e não protege atributos. Veja Escapar a Saída (XSS).

Missão: o endereço do post

Blogs mostram posts em endereços como /post/minha-primeira-receita-pao-de-queijo (um "slug"). Monte esse texto a partir do título.

Missão: transforme o título em minha-primeira-receita-pao-de-queijo: tudo minúsculo (mb_strtolower), sem acentos (strtr com um array de trocas), tudo o que não for letra ou número vira um - (preg_replace("/[^a-z0-9]+/", "-", …)) e sem - nas pontas (trim(…, "-")).

<?php
$titulo = "Minha Primeira Receita: Pão de Queijo!";
$slug = $titulo;
echo $slug, "\n";

<?php
$titulo = "Minha Primeira Receita: Pão de Queijo!";
$slug = mb_strtolower($titulo);
$slug = strtr($slug, ["á" => "a", "ã" => "a", "â" => "a", "é" => "e", "ê" => "e", "í" => "i", "ó" => "o", "õ" => "o", "ô" => "o", "ú" => "u", "ç" => "c"]);
$slug = preg_replace("/[^a-z0-9]+/", "-", $slug);
$slug = trim($slug, "-");
echo $slug, "\n";

Resumo

  • Sem mb_ = bytes; com mb_ = letras. Com acento, use mb_strlen, mb_substr, mb_strtoupper, mb_str_pad.
  • Procurar: str_contains, str_starts_with, str_ends_with (8.0); strpos devolve a posição ou false (compare com !== false).
  • Limpar e trocar: trim, str_replace, strtr, preg_replace.
  • Formatar: sprintf (ponto decimal sempre), number_format (padrão brasileiro com "," e "."), str_pad.
  • Converter: (int)/(float) leem só o começo e não entendem vírgula; valide com is_numeric/ctype_digit.
  • Web: htmlspecialchars na saída, sempre; urlencode/http_build_query para montar URLs.
