PHP Funções de Array

As funções de array que você vai usar no dia a dia, agrupadas pelo que fazem. Cada linha tem a assinatura, uma explicação curta, um exemplo e o resultado real, conferido no PHP 8.5 da máquina da Ana. Para aprender com calma, veja Arrays Indexados, Arrays Associativos, Funções de Array e Ordenar Arrays.

Como ler as tabelas
  • Todos os exemplos partem destas três variáveis (cada exemplo começa do zero, com os valores originais): 
    <?php
$frutas = ["maçã", "banana", "uva"];
$notas  = ["Ana" => 9.5, "Bia" => 7, "Caio" => 8];
$n      = [5, 3, 8, 1];
  • A assinatura mostra os parâmetros e, depois dos dois-pontos, o tipo do resultado: count(array $array): int recebe um array e devolve um int. Parâmetros com = valor são opcionais. &$array quer dizer que a função muda o próprio array (e precisa de uma variável).
  • Os resultados estão escritos como código PHP, no formato curto: ['maçã', 'uva'] é uma lista; ['Ana' => 9.5] mostra as chaves. Quando as chaves de uma lista "pulam" (depois de um unset ou array_filter), elas aparecem: [0 => 5, 2 => 8]. 9.5 é float, 7 é int.
  • Exemplos com duas linhas (como sort($n); e $n): a primeira executa a função, a segunda mostra como o array ficou.

Atalhos: Contar e procurar · Acrescentar e remover · Pedaços, primeiro e último · Chaves e valores · Juntar e comparar · Transformar e calcular · Ordenar · Cursor interno · Aleatório · Armadilhas

Missão: o relatório do estoque

Missão: com as funções desta página, mostre (1) os nomes dos produtos com estoque (estoque > 0), do mais caro ao mais barato, separados por vírgula; (2) o valor total em estoque (preço × estoque de cada um, somado), formatado como R$ 239,50. Sugestão: array_filter, usort com <=>, array_column, array_map, array_sum.

<?php
$produtos = [
    ["nome" => "Caderno", "preco" => 15.90, "estoque" => 3],
    ["nome" => "Caneta", "preco" => 2.50, "estoque" => 0],
    ["nome" => "Mochila", "preco" => 89.90, "estoque" => 2],
    ["nome" => "Lápis", "preco" => 1.20, "estoque" => 10],
];
// 1) Mochila, Caderno, Lápis
// 2) Valor em estoque: R$ 239,50

<?php
$produtos = [
    ["nome" => "Caderno", "preco" => 15.90, "estoque" => 3],
    ["nome" => "Caneta", "preco" => 2.50, "estoque" => 0],
    ["nome" => "Mochila", "preco" => 89.90, "estoque" => 2],
    ["nome" => "Lápis", "preco" => 1.20, "estoque" => 10],
];
$disponiveis = array_filter($produtos, fn($p) => $p["estoque"] > 0);
usort($disponiveis, fn($a, $b) => $b["preco"] <=> $a["preco"]);
echo implode(", ", array_column($disponiveis, "nome")), "\n";
$valor = array_sum(array_map(fn($p) => $p["preco"] * $p["estoque"], $disponiveis));
echo "Valor em estoque: R$ ", number_format($valor, 2, ",", "."), "\n";

Exercícios

1. Qual função ordena $notas da maior nota para a menor mantendo os nomes?

2. O que array_filter([5, 3, 8, 1], fn($x) => $x > 3) devolve?

3. ["a" => 1, "b" => 2] + ["b" => 3, "c" => 4] dá…

Complete para pegar só os nomes de uma lista de produtos (cada um é ["nome" => …, "preco" => …]):

$nomes = ($produtos, "nome");

Complete para saber se todas as notas são maiores ou iguais a 7 (PHP 8.4+):

$todos = ($notas, fn($v) => $v >= 7);

Resumo

  • Procurar: in_array (existe?), array_search (onde? compare com !== false), array_key_exists/isset (a chave existe?), array_find (8.4).
  • Mudar: $a[] =/array_push, array_pop, array_shift, array_unshift, unset, array_splice.
  • Transformar: array_map (cada item vira outro), array_filter (escolhe; mantém as chaves), array_reduce (acumula), array_column (uma coluna).
  • Juntar: array_merge/[...$a, ...$b] (renumera), + (vence o primeiro), implode/explode (texto ↔ array).
  • Ordenar: sort/rsort (renumeram), asort/arsort (valores, mantêm chaves), ksort/krsort (chaves), usort + <=> (sua regra).
