Cada resposta foi conferida num PHP 8.5 de verdade. A correção é na hora; abra "Explicação" para entender o porquê, e o link "Revise" leva à aula do assunto.

Nível 1 · Iniciante

1. O que este código imprime?

echo 10 / 3;
Explicação

No PHP, / sempre faz a divisão "de verdade": 10/3 dá um float, mostrado com até 14 algarismos significativos. Para a divisão inteira, use intdiv(10, 3).

Revise: Operadores Aritméticos

2. O que este código imprime?

echo 10 % 3;
Explicação

% é o resto da divisão inteira: 10 = 3 × 3 + 1.

Revise: Operadores Aritméticos

3. O que este código imprime?

echo "5" + "3";
Explicação

O + é sempre soma. Textos numéricos como "5" e "3" são convertidos para número: 5 + 3 = 8.

Revise: Conversão de Tipos

4. O que este código imprime?

echo "5" . "3";
Explicação

O . é o operador de concatenação: junta os textos sem espaço. No PHP, + soma e . junta; nunca se confundem.

Revise: Operadores de String

5. O que este código imprime?

var_dump(0.1 + 0.2 == 0.3);
Explicação

0.1 e 0.2 não têm representação exata em binário; a soma dá 0.30000000000000004. Nunca compare float com ==: use abs($a - $b) < 0.00001 ou arredonde.

Revise: int e float

6. O que este código imprime?

var_dump(0 == "a");
Explicação

No PHP 8, comparar número com um texto não numérico compara como texto: "0" é diferente de "a". (No PHP 7 isso dava true!)

Revise: Comparação (== e ===)

7. O que este código imprime?

$nome = "Ana";
echo 'Olá, $nome';
Explicação

Aspas simples não trocam variáveis: o texto sai exatamente como foi escrito. Para interpolar, use aspas duplas: "Olá, $nome".

Revise: Interpolação

8. O que este código imprime?

echo strlen("Ação"), " ", mb_strlen("Ação");
Explicação

strlen conta bytes; em UTF-8, "ç" e "ã" ocupam 2 bytes cada: 6. mb_strlen conta letras: 4.

Revise: Acentos e mbstring

9. O que este código imprime?

echo 2 + 3 * 4;
Explicação

Multiplicação vem antes da soma: 3 × 4 = 12, mais 2 = 14. Para somar primeiro: (2 + 3) * 4.

Revise: Precedência

10. O que este código imprime?

echo 2 ** 3 ** 2;
Explicação

O ** (potência) é associativo à direita: 2 ** (3 ** 2) = 29 = 512.

Revise: Precedência

11. O que este código imprime?

$i = 5;
echo $i++ + ++$i;
Explicação

$i++ devolve 5 e depois faz $i virar 6; ++$i soma antes de devolver: 7. Resultado: 5 + 7 = 12. Código assim é difícil de ler: evite.

Revise: Operadores Aritméticos

12. O que este código imprime?

for ($i = 0; $i < 3; $i++) {
    echo $i;
}
Explicação

Começa em 0 e repete enquanto $i < 3: 0, 1, 2. O echo não pula linha, então sai tudo junto.

Revise: for

13. O que este código imprime?

$a = [3, 1, 2];
sort($a);
echo implode(",", $a);
Explicação

sort ordena o próprio array (não devolve um novo) em ordem crescente; implode junta com vírgulas.

Revise: Ordenar Arrays

14. O que este código imprime (resumindo a saída do print_r)?

$x = ["x" => 1];
$x[] = 5;
print_r($x);
Explicação

$x[] = 5 usa a próxima chave numérica livre. Como ainda não havia nenhuma chave numérica, ela é 0.

Revise: Arrays Associativos

15. O que este código imprime?

$nota = 7;
echo match (true) {
    $nota >= 9 => "A",
    $nota >= 6 => "B",
    default    => "C",
};
Explicação

match (true) devolve o primeiro braço cuja condição é true: 7 >= 9 é falso; 7 >= 6 é verdadeiro, então "B".

Revise: match

16. O que este código imprime?

$n = 1;
switch ($n) {
    case 1:
        echo "um ";
    case 2:
        echo "dois ";
        break;
    default:
        echo "outro";
}
Explicação

Sem break no case 1, o switch "cai" no caso seguinte e só para no break do case 2. É o motivo de o match existir.

Revise: switch

17. O que este código imprime?

var_dump((int) "12abc");
Explicação

A conversão forçada (int) pega os algarismos do começo e ignora o resto, sem aviso. (Numa conta, "12abc" + 1 daria Warning: A non-numeric value encountered.)

Revise: Conversão de Tipos

18. O que este código imprime?

var_dump((bool) "0");
Explicação

O texto "0" é um dos valores que viram false, junto com "", 0, 0.0, [] e null. Já "0.0" e " " são true.

Revise: Booleanos

19. O que este código imprime?

echo number_format(1234.567, 2, ",", ".");
Explicação

Os argumentos são: casas decimais (2), separador decimal (,) e separador de milhar (.). O número é arredondado: .567 vira ,57.

Revise: Formatar Números

20. O que este código imprime?

printf("%05.1f", 3.14159);
Explicação

%05.1f: número com 1 casa decimal, ocupando no mínimo 5 caracteres, completado com zeros à esquerda. "3.1" tem 3 caracteres, então ganha dois zeros. O printf sempre usa ponto, não importa o idioma.

Revise: printf e sprintf

21. O que este código imprime?

[$a, $b] = [1, 2];
[$a, $b] = [$b, $a];
echo $a, $b;
Explicação

A segunda linha troca os valores de lugar: o array [$b, $a] (2, 1) é montado antes de ser desestruturado em $a e $b.

Revise: Desestruturação (list)

22. O que este código imprime?

var_dump(null ?? "padrão");
Explicação

O ?? devolve o lado direito porque o esquerdo é null. E o var_dump conta bytes: "padrão" tem 6 letras, mas o "ã" ocupa 2 bytes em UTF-8, então 7.

Revise: ?? e ?-> · var_dump e print_r

23. O que este código imprime?

$total = 0;
$i = 10;
while ($i > 0) {
    $total += $i;
    $i -= 4;
}
echo $total;
Explicação

O laço soma 10, depois 6, depois 2 (e para, porque o próximo seria -2): 10 + 6 + 2 = 18.

Revise: while e do-while

24. O que este código imprime?

var_dump("abc" == 0, "1" == "01", "10" == "1e1");
Explicação

(As respostas resumem os três bool(…).) "abc" == 0 é falso no PHP 8. Dois textos numéricos são comparados como números: "1" == "01" e "10" == "1e1" (1×10¹) são verdadeiros. Com ===, os três seriam falsos.

Revise: Comparação (== e ===)

Nível 2 · Intermediário

25. O que este código imprime?

function somar(int ...$n): int {
    return array_sum($n);
}
echo somar(1, 2, 3);
Explicação

Os ... juntam todos os argumentos num array: [1, 2, 3]; array_sum soma: 6.

Revise: Funções Variádicas

26. O que este código imprime?

function area($largura = 2, $altura = 3) {
    return $largura * $altura;
}
echo area(altura: 10);
Explicação

Com argumentos nomeados, você passa só o que quer: $largura fica no padrão 2 e $altura vale 10: 2 × 10 = 20.

Revise: Parâmetros

27. O que este código imprime?

$x = 1;
function teste() {
    return isset($x) ? "sim" : "não";
}
echo teste();
Explicação

Dentro da função, $x é outra variável, local e inexistente: as funções não enxergam as variáveis de fora. O isset não dá aviso; só responde false.

Revise: Escopo

28. O que este código imprime?

function contar() {
    static $n = 0;
    return ++$n;
}
contar();
contar();
echo contar();
Explicação

Uma variável static guarda o valor entre as chamadas: 1, 2 e, na terceira, 3.

Revise: Escopo (global e static)

29. O que este código imprime?

$taxa = 1;
$f = function () use ($taxa) {
    return $taxa;
};
$taxa = 2;
echo $f();
Explicação

O use ($taxa) copia o valor no momento em que a função é criada (1). Mudar $taxa depois não afeta a cópia. Para acompanhar as mudanças, seria use (&$taxa).

Revise: Funções Anônimas e Arrow Functions

30. O que este código imprime?

echo implode(",", array_map(fn($n) => $n * 2, [1, 2, 3]));
Explicação

array_map aplica a função em cada item e devolve um array novo: [2, 4, 6].

Revise: Funções de Array

31. O que este código imprime?

$r = array_filter([1, 0, 2, null, 3]);
echo implode(",", array_keys($r));
Explicação

Sem função, array_filter remove os valores "falsos" (0 e null) mas mantém as chaves originais: 0, 2 e 4. Para renumerar: array_values.

Revise: Funções de Array

32. O que este código imprime (o texto enviado, não o que o navegador mostra)?

echo htmlspecialchars("<b>Ana & Bia</b>");
Explicação

O htmlspecialchars troca <, > e & pelas entidades. No navegador, isso aparece como o texto <b>Ana & Bia</b>, sem virar negrito: é a proteção contra XSS.

Revise: Escapar a Saída (XSS)

33. O que este código imprime?

echo json_encode(["nome" => "Zé", "idade" => 30]);
Explicação

Por padrão, o json_encode escreve letras acentuadas como \u00e9 (é JSON válido). Para manter o "é", use a opção JSON_UNESCAPED_UNICODE.

Revise: JSON

34. O que este código imprime?

try {
    echo "A";
    throw new Exception("ops");
    echo "B";
} catch (Exception $e) {
    echo "C";
} finally {
    echo "D";
}
Explicação

"A" sai; o throw pula direto para o catch (o "B" nunca roda), que imprime "C"; o finally roda sempre: "D".

Revise: Exceções (try e catch)

35. O que este código imprime?

try {
    echo 1 % 0;
} catch (DivisionByZeroError $e) {
    echo $e->getMessage();
}
Explicação

Resto por zero lança DivisionByZeroError com a mensagem "Modulo by zero" (a divisão / por zero usa "Division by zero"). Como ele foi pego pelo catch, o programa não para.

Revise: Exceções (try e catch)

36. O que este código imprime?

function fat(int $n): int {
    return $n <= 1 ? 1 : $n * fat($n - 1);
}
echo fat(5);
Explicação

fat(5) = 5 × fat(4) = 5 × 4 × 3 × 2 × 1 = 120. O caso $n <= 1 é o que faz a recursão parar.

Revise: Recursão

37. O que este código imprime?

echo date("d/m/Y", mktime(0, 0, 0, 2, 30, 2026));
Explicação

O mktime não reclama de datas impossíveis: ele "transborda". 30 de fevereiro de 2026 (ano com 28 dias em fevereiro) vira 2 de março. Para validar uma data, use checkdate.

Revise: Datas e Horas

38. O que este código imprime?

echo count(explode(",", "a,,b"));
Explicação

Entre as duas vírgulas há um texto vazio, que também vira um item: ["a", "", "b"].

Revise: Funções de String

39. O que este código imprime?

var_dump(str_contains("Guia PHP", "php"));
Explicação

str_contains diferencia maiúsculas de minúsculas: "php" não está em "Guia PHP". Para ignorar: str_contains(mb_strtolower($t), "php").

Revise: Funções de String

40. O que este código imprime?

$frutas = ["banana", "Abacaxi", "abacate"];
sort($frutas);
echo implode(" ", $frutas);
Explicação

O sort compara os bytes: as maiúsculas vêm antes de todas as minúsculas. Para ignorar a diferença: sort($frutas, SORT_FLAG_CASE | SORT_STRING) ou natcasesort.

Revise: Ordenar Arrays

41. O que este código imprime?

echo gettype(json_decode('{"a": 1}')), " ", gettype(json_decode('{"a": 1}', true));
Explicação

Sem o segundo argumento, json_decode devolve um objeto (stdClass, lido com ->); com true, um array associativo.

Revise: JSON

42. O que este código imprime?

$texto = "a-b-c";
echo str_replace("-", "", $texto), " ", ucfirst("ana"), " ", strrev("ana");
Explicação

str_replace tira os hífens; ucfirst põe só a primeira letra em maiúscula; strrev inverte o texto, e "ana" de trás para frente é "ana".

Revise: Funções de String

43. O endereço é index.php?nome=Ana&nome=Bia. O que echo $_GET["nome"]; mostra?

Explicação

Quando o mesmo nome aparece duas vezes, o último vence: "Bia" (conferido com php -S e curl). Para receber vários valores, o nome precisa de colchetes: nome[]=Ana&nome[]=Bia vira um array.

Revise: $_GET e $_POST

44. Um formulário de login salva o usuário e mostra "Bem-vinda!". Depois, a pessoa aperta F5. Sem o padrão Post/Redirect/Get, o que acontece?

Explicação

A página atual é a resposta de um POST, e recarregar repete o POST. Redirecionando depois de processar (header("Location: …"); exit;), a página final vem de um GET.

Revise: header e Redirecionamento · Projeto Formulário de Contato

45. Qual destas consultas é segura contra injeção de SQL?

Explicação

Só o prepared statement envia o valor separado do comando. Pôr aspas em volta não resolve (basta enviar uma aspa), e o htmlspecialchars protege o HTML, não o SQL.

Revise: Prepared Statements e SQL Injection

46. Como guardar a senha de um usuário no banco?

Explicação

password_hash usa um algoritmo lento de propósito (bcrypt) e um sal aleatório. md5 é rápido demais e já tem tabelas prontas de senhas; base64 nem é hash, é só outra forma de escrever.

Revise: Senhas (password_hash)

Nível 3 · Avançado

47. O que este código imprime?

class Pessoa {
    public function __construct(public string $nome = "Ana") {}
}
echo (new Pessoa)->nome;
Explicação

Com a promoção no construtor, public string $nome = "Ana" cria a propriedade e a preenche. Sem argumento, vale o padrão.

Revise: Construtores

48. O que este código imprime?

class A {
    public static function criar(): static {
        return new static();
    }
}
class B extends A {}
echo get_class(B::criar());
Explicação

new static() cria um objeto da classe usada na chamada (B::criar()), não da classe onde o método foi escrito. É o "late static binding"; com new self(), seria A.

Revise: static

49. O que acontece?

abstract class Forma {}
$f = new Forma();
Explicação

Classe abstrata não vira objeto: ela só serve de base para outras (class Circulo extends Forma).

Revise: Classes Abstratas

50. O que acontece na última linha?

class Produto {
    public function __construct(public readonly float $preco) {}
}
$p = new Produto(10);
$p->preco = 20;
Explicação

Uma propriedade readonly recebe valor uma única vez (no construtor). Para "mudar", crie outro objeto (ou use clone com as novidades do PHP 8.5, quando a classe permite).

Revise: readonly e Property Hooks

51. O que este código imprime?

enum Status: string {
    case Pago = "pago";
    case Pendente = "pendente";
}
echo Status::from("pago")->name;
var_dump(Status::tryFrom("cancelado"));
Explicação

from("pago") acha o caso pelo valor; ->name é o nome do caso: "Pago". tryFrom com um valor que não existe devolve null (o from lançaria ValueError).

Revise: Enums

52. O que este código imprime?

echo match ("1") {
    1   => "int",
    "1" => "string",
};
Explicação

O match compara com ===: o texto "1" não é idêntico ao número 1, então o primeiro braço não serve.

Revise: match

53. O que este código imprime?

trait Saudacao {
    public function oi(): string {
        return "Oi de " . static::class;
    }
}
class Loja {
    use Saudacao;
}
echo (new Loja)->oi();
Explicação

O código do trait é "colado" na classe que o usa; dentro dele, static::class é a classe do objeto: Loja.

Revise: Traits

54. O que este código imprime?

$pedido = null;
var_dump($pedido?->cliente?->nome);
Explicação

O ?-> (nullsafe) para a cadeia ao encontrar null e devolve null, sem aviso.

Revise: ?? e ?->

55. O que este código imprime?

echo "  ana  " |> trim(...) |> ucfirst(...);
Explicação

O pipe |> PHP 8.5+ passa o valor para a próxima função: trim tira os espaços e ucfirst põe a inicial maiúscula. É o mesmo que ucfirst(trim(" ana ")).

Revise: Operador Pipe (|>)

56. O que este código imprime?

echo array_first([3, 1, 2]), array_last([3, 1, 2]);
Explicação

array_first e array_last PHP 8.5+ devolvem o primeiro e o último valor, sem ordenar: 3 e 2.

Revise: Novidades do 8.0 ao 8.5 · Funções de Array

57. O que este código imprime?

$f = strtoupper(...);
echo $f("oi");
Explicação

strtoupper(...) não chama a função: cria um objeto Closure que aponta para ela. Depois, $f("oi") chama.

Revise: Callables de Primeira Classe

58. O que este código imprime?

class Conta {
    public int $saldo = 0 {
        set => max(0, $value);
    }
}
$c = new Conta;
$c->saldo = -50;
echo $c->saldo;
Explicação

O gancho set PHP 8.4+ roda a cada atribuição; na forma curta (=>), o resultado da expressão é o que fica guardado: max(0, -50) = 0.

Revise: readonly e Property Hooks

59. O que este código imprime?

namespace Loja;
class Produto {}
echo Produto::class;
Explicação

::class dá o nome completo da classe, com o namespace.

Revise: Namespaces

60. O que acontece?

declare(strict_types=1);
function dobro(int $n): int {
    return $n * 2;
}
echo dobro("5");
Explicação

Com strict_types=1, o PHP não converte "5" em 5 para você: o tipo tem que ser exatamente int. Sem essa linha, imprimiria 10.

Revise: Tipos e Retorno

61. O que este código imprime?

interface Pagavel {}
class Pix implements Pagavel {}
var_dump(new Pix instanceof Pagavel);
Explicação

instanceof vale para a classe, as classes-mãe e as interfaces que ela implementa.

Revise: Interfaces

62. O que este código imprime?

final class Ponto {
    public function __construct(public int $x = 0, public int $y = 0) {}
}
$a = new Ponto(1, 2);
$b = clone($a, ["y" => 9]);
echo $a->y, $b->y;
Explicação

O clone com um array de propriedades PHP 8.5+ ("clone with") cria a cópia já com y = 9. O original não muda: 2 e 9.

Revise: Novidades do 8.0 ao 8.5

63. O que este código imprime?

class Item {
    public function __toString(): string {
        return "Café";
    }
}
echo "Produto: " . new Item;
Explicação

Ao usar um objeto como texto, o PHP chama o método mágico __toString.

Revise: Métodos Mágicos

64. O que este código imprime?

$a = [1, 2, 3];
foreach ($a as &$v) {
    $v *= 2;
}
unset($v);
echo implode(",", $a);
Explicação

Com &$v, o foreach trabalha com o próprio item do array, não com uma cópia. O unset($v) depois do laço é um bom hábito: desfaz a ligação com o último item.

Revise: foreach

65. A classe App\Modelo\Usuario segue a PSR-4, com "App\\": "src/" no composer.json. Em que arquivo ela fica?

Explicação

O prefixo App\ corresponde à pasta src/; o resto do nome vira o caminho: Modelo\Usuario → src/Modelo/Usuario.php.

Revise: Autoload e PSR-4 · Composer
