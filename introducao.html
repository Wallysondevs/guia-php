PHP Introdução

O PHP é uma linguagem de programação feita para construir sites que mudam sozinhos: páginas que mostram o seu nome depois do login, o seu carrinho de compras, os comentários mais recentes. Ele roda no servidor (o computador onde o site mora), monta a página e a entrega pronta para o navegador. Nesta aula você vai entender o que isso quer dizer, onde o PHP é usado, de onde ele veio e como ele se compara com outras linguagens famosas.

Você vai aprender
  • O que é uma linguagem de programação e o que é o PHP.
  • A diferença entre uma página estática e uma página dinâmica.
  • Onde o PHP é usado: WordPress, Laravel, lojas, sistemas de escola, APIs.
  • A história do nome: de "Personal Home Page" a "PHP: Hypertext Preprocessor".
  • Como o PHP se compara com o JavaScript e o Python.
  • O que você vai conseguir fazer ao terminar o guia.

Primeiro: o que é programar?

Um computador não "entende" nada sozinho. Ele só sabe seguir instruções, uma de cada vez, muito rápido. Programar é escrever essas instruções. Uma linguagem de programação é o idioma combinado entre você e o computador: um conjunto de palavras e símbolos com regras rígidas (onde vai o ponto e vírgula, onde abrem e fecham as aspas).

Pense numa receita de bolo. Ela tem uma lista de passos, em ordem: "pré-aqueça o forno", "misture os ovos com o açúcar", "se a massa estiver grossa, acrescente leite". Um programa é igual: uma lista de passos, alguns com decisões ("se…") e repetições ("bata até ficar homogêneo"). A diferença é que o computador segue a receita ao pé da letra. Se você escrever "açúcer", ele não adivinha que era "açúcar": ele para e reclama. Essas reclamações são as mensagens de erro, e o guia vai ensinar você a lê-las.

O programa que lê o seu código PHP e executa as instruções também se chama php. Ele é um interpretador: lê o arquivo de cima para baixo e vai fazendo o que está escrito. Você não precisa "transformar" o código antes de rodar, como em algumas linguagens (o Java e o C, por exemplo, precisam ser compilados antes).

Página estática × página dinâmica

Para entender para que o PHP serve, compare dois tipos de página da web.

Uma página estática é um arquivo HTML comum (HTML é a linguagem que descreve o conteúdo de uma página: títulos, parágrafos, imagens, links). Ela é como um cartaz impresso: todo mundo que olha vê exatamente a mesma coisa. Para mudar o texto, alguém precisa editar o arquivo à mão.

Uma página dinâmica é como um atendente de balcão: cada pessoa que chega recebe uma resposta montada para ela. O atendente pergunta o nome, consulta o estoque, confere o horário e só então responde. É isso que o PHP faz: a cada visita, ele roda o seu código e monta o HTML na hora.

Veja os dois na prática. A Ana tem, na pasta site, um arquivo estático oi.html e um arquivo PHP oi.php:

<p>Olá, visitante!</p>

<?php
$nome = $_GET["nome"] ?? "visitante";
?>
<p>Olá, <?= htmlspecialchars($nome) ?>!</p>

Você ainda não precisa entender o oi.php por inteiro; cada pedaço tem a sua aula. Por enquanto, a ideia geral:

<?php … ?>
Um trecho de código PHP. Tudo o que está fora dessas marcas é HTML comum, que o PHP manda para o navegador sem mexer.
$nome = …
Cria uma variável chamada $nome: uma "caixinha" com um valor dentro (aula Variáveis).
$_GET["nome"] ?? "visitante"
Pega o nome que veio no endereço da página (?nome=Ana); se não veio nenhum, usa "visitante" (aulas $_GET e $_POST e ?? e ?->).
<?= … ?>
Escreve um valor no meio do HTML.
htmlspecialchars(…)
Uma proteção: impede que alguém mal-intencionado coloque código no lugar do nome. O guia usa essa proteção desde o começo (aula Escapar a Saída).

Agora a Ana liga o servidor de testes do PHP (o php -S, que você vai conhecer em O Servidor Embutido) e pede as páginas com o curl, um programa de terminal que faz o mesmo pedido que um navegador faria e mostra o HTML recebido:

$ curl "localhost:8000/oi.php?nome=Ana"
<p>Olá, Ana!</p>                  « o PHP montou a página com o nome da Ana
$ curl "localhost:8000/oi.php?nome=Bruno"
<p>Olá, Bruno!</p>                « o mesmo arquivo, outra resposta
$ curl "localhost:8000/oi.php"
<p>Olá, visitante!</p>            « sem nome no endereço: o valor padrão
$ curl "localhost:8000/oi.html?nome=Ana"
<p>Olá, visitante!</p>            « a página estática ignora o nome: é sempre igual

Um único arquivo oi.php gerou três páginas diferentes. Agora imagine que, em vez do nome vindo no endereço, o PHP buscasse num banco de dados os produtos da loja, as notas do aluno ou as mensagens novas. É exatamente assim que funcionam as lojas virtuais, os portais de notícia e as redes sociais.

Repare também no que não apareceu: nenhum <?php, nenhum $nome. O navegador recebe só o HTML pronto. O código PHP fica guardado no servidor, longe dos olhos de quem visita. A aula Como o PHP Funciona detalha esse caminho.

Experimente a mesma página aqui. Esta caixa funciona em modo web: o código é tratado como uma página, aberta no endereço /index.php?nome=Ana.

Missão: rode e veja Olá, Ana!. Depois troque a palavra Olá por Bom dia (só no HTML, fora do PHP) e rode de novo. A página deve dizer Bom dia, Ana!.

<?php
$nome = $_GET["nome"] ?? "visitante";
?>
<p>Olá, <?= htmlspecialchars($nome) ?>!</p>

<?php
$nome = $_GET["nome"] ?? "visitante";
?>
<p>Bom dia, <?= htmlspecialchars($nome) ?>!</p>

PHP sozinho, sem página nenhuma

O PHP também roda fora da web, direto no terminal, como uma linguagem comum: para processar planilhas, mandar e-mails agendados, limpar arquivos, fazer contas. É por aí que o guia começa, porque é o jeito mais simples de ver um programa funcionando. A aula PHP na Linha de Comando mostra esse uso.

Um pouco de história

A história do PHP explica muito do jeito dele. Ele não foi planejado por um comitê: nasceu como uma ferramenta pessoal e cresceu porque resolvia problemas reais.

AnoO que aconteceu
1994Rasmus Lerdorf, um programador nascido na Groenlândia e criado na Dinamarca, escreve pequenos programas para saber quantas pessoas visitavam o currículo dele na internet. Ele chama o conjunto de Personal Home Page Tools, "ferramentas para página pessoal". Daí a sigla PHP.
1995Rasmus publica as ferramentas na internet, de graça e com o código aberto, para quem quisesse usar e melhorar.
1997–1998Dois estudantes israelenses, Andi Gutmans e Zeev Suraski, reescrevem o coração da linguagem. Sai o PHP 3, e o nome muda para PHP: Hypertext Preprocessor ("pré-processador de hipertexto").
2000PHP 4, com o motor Zend Engine (o nome junta Zeev e Andi).
2004PHP 5: orientação a objetos de verdade e o PDO para bancos de dados.
2015PHP 7: cerca de duas vezes mais rápido que o 5. (Houve um PHP 6, mas o projeto foi abandonado antes de ser lançado; por isso o número foi pulado.)
2020PHP 8.0: match, argumentos nomeados, atributos e o compilador JIT.
2021Nasce a PHP Foundation, que paga desenvolvedores para cuidar da linguagem.
2025PHP 8.5 (20 de novembro): operador pipe |>, array_first, array_last e mais. É a versão que este guia ensina.

Um nome que se explica sozinho

Repare em "PHP: Hypertext Preprocessor". A primeira letra da sigla é a própria sigla: PHP quer dizer "PHP: Hypertext Preprocessor", que quer dizer "PHP: Hypertext Preprocessor"… Isso se chama acrônimo recursivo, uma brincadeira comum entre programadores (o GNU, do Linux, também é um: "GNU's Not Unix").

E o que é "pré-processador de hipertexto"? Hipertexto é texto com links, ou seja, HTML (HyperText Markup Language). Pré-processar é trabalhar no texto antes de ele ir para o navegador. O nome descreve exatamente o que você viu no oi.php: o PHP mexe no HTML antes da entrega.

Por que o PHP tem fama de "bagunçado"?

Como cresceu aos poucos, o PHP antigo acumulou nomes de funções sem padrão (strlen, str_replace, htmlspecialchars) e comportamentos que surpreendiam. O PHP moderno (do 7 em diante, e principalmente do 8) corrigiu muito disso: tem tipos, erros mais claros e recursos de linguagens modernas. Este guia ensina o PHP de hoje e avisa quando uma coisa antiga ainda pode aparecer em código que você encontrar por aí.

Preciso saber HTML antes?

Ajuda, mas não é obrigatório. O Nível 1 começa com programas de terminal, que não usam HTML. Quando o HTML aparece, o guia explica as marcas usadas (<p> é parágrafo, <h1> é título, <ul> e <li> são listas). Se quiser se aprofundar, qualquer curso básico de HTML de uma ou duas tardes basta.

Quando dá errado

Ainda não escrevemos programas, mas há três confusões muito comuns em quem está começando a mexer com PHP:

Abri o arquivo .php com dois cliques e apareceu o código (ou o navegador quis baixar o arquivo)

O que aconteceu: o navegador abriu o arquivo direto do disco (o endereço começa com file://). Sem um servidor, ninguém rodou o PHP: o navegador tratou o arquivo como texto ou HTML comum, e mostrou o código cru (ou um pedaço dele).

Como resolver: o PHP precisa de alguém que o execute. No terminal: php oi.php. Como página: ligue o servidor com php -S localhost:8000 e abra http://localhost:8000/oi.php. Veja O Servidor Embutido.

"Cliquei em Exibir código-fonte e não achei o meu PHP"

O que aconteceu: não é erro, é o normal. O navegador só recebe o HTML que o PHP gerou. O código PHP nunca sai do servidor. Isso é bom: senhas do banco de dados e regras do sistema ficam escondidas de quem visita o site.

Como ver o código: abra o arquivo .php no seu editor de código (aula Editores e IDEs), não no navegador.

"Coloquei PHP num arquivo .html e não funcionou" 
<p>Olá, <?= "Ana" ?>!</p>

$ curl localhost:8000/teste.html
<p>Olá, <?= "Ana" ?>!</p>          « entregue como está: o PHP nem foi chamado
$ curl localhost:8000/teste.php
<p>Olá, Ana!</p>                     « passou pelo PHP

O que aconteceu: os servidores só passam pelo PHP os arquivos terminados em .php. Um .html é entregue como está, com o <?= e tudo. No navegador, o resultado parece ainda mais estranho: ele trata <?= "Ana" ?> como uma marca que não conhece e a esconde, e a página mostra só Olá, !.

Como resolver: renomeie o arquivo para .php.

Resumo

  • Programar é escrever instruções para o computador; o PHP é uma linguagem de programação, e o programa php é o interpretador que as executa.
  • O PHP roda no servidor e gera páginas dinâmicas: o mesmo arquivo responde diferente a cada visita.
  • O navegador recebe só o HTML gerado; o código PHP nunca sai do servidor.
  • O PHP está em 69,4% dos sites com linguagem conhecida e o WordPress em 39,7% de todos os sites (W3Techs, 16/10/2026).
  • Nasceu em 1994 como Personal Home Page Tools, de Rasmus Lerdorf; desde o PHP 3 se chama PHP: Hypertext Preprocessor.
  • PHP (servidor), JavaScript (navegador) e Python (uso geral) se complementam.
