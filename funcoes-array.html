PHP Funções de Array

O PHP traz mais de 70 funções prontas para trabalhar com arrays. Você não precisa decorar nenhuma: precisa saber que elas existem, para não escrever à mão um laço que já vem pronto. Esta aula mostra as que aparecem em quase todo programa, agrupadas pelo que fazem, com a saída real de cada uma. A lista completa, para consulta, está na Referência de Funções de Array.

Você vai aprender
  • A diferença entre funções que devolvem um array novo e funções que mudam o array que você passou.
  • Procurar: in_array (e o modo estrito), array_search, array_find, array_any, array_all.
  • Chaves e valores: array_keys, array_values, array_first, array_last.
  • Juntar e cortar: array_merge × +, array_slice, array_splice.
  • Pilha e fila: array_push, array_pop, array_shift, array_unshift.
  • Transformar: array_map, array_filter, array_reduce.
  • Contas e limpeza: array_sum, array_unique, array_column, range.

Nos exemplos, quando a ordem das chaves não importa, a saída usa implode(", ", …) para mostrar o array numa linha só; quando as chaves importam, usa print_r.

Antes de tudo: devolve um novo ou muda o original?

As funções de array se dividem em dois grupos, e confundir os dois é o erro número um desta aula:

TipoComo usarExemplos
Devolvem um array novo; o original fica igualGuarde o resultado: $novo = array_map(…, $a);array_map, array_filter, array_slice, array_merge, array_unique, array_values, array_reverse
Mudam o array que você passou (recebem o array "por referência")Só chame: array_push($a, "x");array_push, array_pop, array_shift, array_unshift, array_splice, sort e companhia
<?php
$fila = ["Ana", "Bruno"];
$fila[] = "Carla";
array_push($fila, "Diego");                       // muda $fila
echo implode(", ", $fila), "\n";
array_filter($fila, fn($n) => $n !== "Ana");      // devolve um novo... que ninguém guardou
echo implode(", ", $fila), "\n";

$ php f-ref3.php
Ana, Bruno, Carla, Diego
Ana, Bruno, Carla, Diego        « a Ana continua: o resultado do array_filter foi jogado fora

O certo seria $fila = array_filter($fila, …);. Quando uma função "não fez nada", a primeira pergunta é: ela devolve um array novo que eu esqueci de guardar? A passagem "por referência" é explicada na aula Parâmetros.

Procurar

in_array: "está na lista?"

in_array(valor, array) responde true ou false. O nome é literal: "no array".

<?php
$compras = ["arroz", "feijão", "café"];
var_dump(in_array("café", $compras));
var_dump(in_array("Café", $compras));
var_dump(in_array("leite", $compras));

$codigos = [7, 12, 30];
var_dump(in_array("7", $codigos));
var_dump(in_array("7", $codigos, true));
var_dump(in_array(7, $codigos, true));

var_dump(in_array(true, ["qualquer coisa"]));
var_dump(in_array(true, ["qualquer coisa"], true));
var_dump(in_array(null, [0, 1]));

$ php f-inarray.php
bool(true)
bool(false)             « diferencia maiúsculas: "Café" não é "café"
bool(false)
bool(true)              « o texto "7" foi considerado igual ao número 7
bool(false)             « com true no fim (modo estrito), "7" não é 7
bool(true)
bool(true)              « true == "qualquer coisa"?! sem modo estrito, sim
bool(false)
bool(true)              « null == 0, sem modo estrito

Por padrão, o in_array compara com == (igualdade "frouxa", que converte tipos). O terceiro argumento, true, liga o modo estrito: a comparação passa a ser === (mesmo valor e mesmo tipo). As diferenças entre == e === estão em Comparação.

Use o modo estrito sempre que puder

in_array($x, $lista, true) evita as surpresas das três últimas linhas. Ele só atrapalha quando os tipos podem mesmo variar, por exemplo um código que chega como texto de um formulário ("7") e uma lista de números; aí converta antes ((int) $codigo) e continue usando o modo estrito.

array_search: "em que posição está?"

Parecida com in_array, mas devolve a chave onde achou o valor, ou false se não achou. Também aceita o true no fim, para o modo estrito.

<?php
$compras = ["arroz", "feijão", "café"];
var_dump(array_search("café", $compras));
var_dump(array_search("arroz", $compras));
var_dump(array_search("leite", $compras));

$precos = ["café" => 18.9, "pão" => 0.75, "leite" => 5.49];
var_dump(array_search(0.75, $precos));

if (!array_search("arroz", $compras)) {
    echo "Não achei arroz?!\n";
}
$pos = array_search("arroz", $compras);
if ($pos !== false) {
    echo "Arroz está na posição $pos\n";
}

$ php f-search.php
int(2)
int(0)                  « achou, na posição 0
bool(false)             « não achou
string(4) "pão"         « num array associativo, devolve a chave com nome
Não achei arroz?!       « ERRADO: o 0 foi tratado como "falso"
Arroz está na posição 0 « certo: comparar com !== false
A armadilha do 0

Quando o valor está na posição 0, o array_search devolve 0, e o if trata 0 como falso (veja Booleanos). Nunca teste o resultado com if (!array_search(…)). Teste com !== false, ou use in_array se só precisa saber se existe.

array_find, array_find_key, array_any, array_all PHP 8.4+

in_array procura um valor exato. Para procurar por uma condição ("o primeiro aluno com nota menor que 7"), o PHP 8.4 trouxe quatro funções que recebem uma pequena função com a pergunta. A forma fn($a) => … é uma arrow function: uma função de uma linha, escrita ali mesmo. Por enquanto leia como "para cada $a, responda isto"; ela é explicada em Funções Anônimas e Arrow Functions.

<?php
$alunos = [
    ["nome" => "Ana",   "nota" => 9.5],
    ["nome" => "Bruno", "nota" => 6.0],
    ["nome" => "Carla", "nota" => 8.5],
];
$primeiroReprovado = array_find($alunos, fn($a) => $a["nota"] < 7);
print_r($primeiroReprovado);
var_dump(array_find($alunos, fn($a) => $a["nota"] > 10));
var_dump(array_find_key($alunos, fn($a) => $a["nome"] === "Carla"));
var_dump(array_any($alunos, fn($a) => $a["nota"] < 7));
var_dump(array_all($alunos, fn($a) => $a["nota"] >= 5));
var_dump(array_all([], fn($a) => false));

array_values é também a forma de renumerar um array cheio de buracos (depois de um unset ou de um array_filter). array_key_first e array_key_last (PHP 7.3) dão a primeira e a última chave.

array_first e array_last PHP 8.5+

Para pegar o primeiro ou o último valor, sem se preocupar com as chaves, o PHP 8.5 trouxe estas duas:

<?php
$fila = ["Ana", "Bruno", "Carla"];
var_dump(array_first($fila));
var_dump(array_last($fila));
$precos = ["café" => 18.9, "pão" => 0.75];
var_dump(array_last($precos));
var_dump(array_first([]));

$ php f-first.php

string(5) "Carla"
float(0.75)             « funciona com chaves de nome
NULL                    « array vazio: null, sem aviso

Em versões anteriores, use $a[array_key_last($a)], ou $a[count($a) - 1] se os índices forem 0, 1, 2… em sequência (veja Arrays Indexados).

Juntar: array_merge × +

Há duas formas de juntar arrays, e elas fazem coisas diferentes. Primeiro, com listas:

<?php
$manha = ["Ana", "Bruno"];
$noite = ["Carla", "Diego", "Elisa"];
print_r(array_merge($manha, $noite));
print_r($manha + $noite);

$ php f-merge.php
Array
(

    [1] => Bruno
    [2] => Carla

    [4] => Elisa

    [0] => Ana              « +: as chaves 0 e 1 já existiam à esquerda,
    [1] => Bruno            « então Carla e Diego foram ignorados;

O + não "soma" listas: ele junta por chave, e quem chegou primeiro (à esquerda) fica. Com listas, isso quase nunca é o que você quer. Com arrays associativos, os dois são úteis:

$padrao  = ["cor" => "azul", "tamanho" => "M", "fonte" => "Arial"];
$escolha = ["cor" => "verde", "tamanho" => "G"];
print_r(array_merge($padrao, $escolha));
print_r($escolha + $padrao);
print_r($padrao + $escolha);

Chaves de nome repetidasVence $b (direita)Vence $a (esquerda)

Uma terceira forma, moderna, é o spread: [...$manha, ...$noite], que funciona como o array_merge. Ela é explicada em Desestruturação.

Cortar: array_slice e array_splice

Os nomes são quase iguais, mas o comportamento é oposto. array_slice ("fatia") copia um pedaço e deixa o original intacto. array_splice ("emenda") tira (e opcionalmente põe) itens no próprio array.

<?php
$fila = ["Ana", "Bruno", "Carla", "Diego", "Elisa"];
echo implode(", ", array_slice($fila, 1, 2)), "\n";
echo implode(", ", array_slice($fila, 3)), "\n";
echo implode(", ", array_slice($fila, -2)), "\n";
print_r(array_slice($fila, 2, 2));
print_r(array_slice($fila, 2, 2, true));
echo "A fila continua: ", implode(", ", $fila), "\n";
array_slice($fila, 1, 2)
A partir da posição 1, pegue 2 itens: Bruno e Carla.
array_slice($fila, 3)
Sem a quantidade: da posição 3 até o fim.
array_slice($fila, -2)
Posição negativa conta do fim: os 2 últimos. (Aqui o negativo funciona; em $fila[-1], não.)
…, true
O 4º argumento mantém as chaves originais, em vez de renumerar.

O array_slice é o jeito de fazer paginação ("mostre os itens 11 a 20"): array_slice($produtos, 10, 10).

<?php
$fila = ["Ana", "Bruno", "Carla", "Diego", "Elisa"];
$saiu = array_splice($fila, 1, 2);
echo "Saíram: ", implode(", ", $saiu), "\n";
echo "Ficou:  ", implode(", ", $fila), "\n";
array_splice($fila, 1, 0, ["Fábio", "Gabi"]);
echo "Depois de inserir: ", implode(", ", $fila), "\n";
array_splice($fila, 0, 1, "Helena");
echo "Depois de trocar:  ", implode(", ", $fila), "\n";

$ php f-splice.php

Os argumentos do array_splice são: o array, a posição, quantos tirar, e (opcional) o que colocar no lugar. Ele devolve os itens retirados e renumera o array, sem deixar buracos (ao contrário do unset).

Pilha e fila: push, pop, shift, unshift

Quatro funções para pôr e tirar nas pontas. Todas mudam o array.

echo "pop tirou $ultimo: ", implode(", ", $fila), "\n";

  • Fila (como a fila do banco: o primeiro a chegar é o primeiro atendido): array_push + array_shift.

Transformar: array_map, array_filter, array_reduce

Estas três recebem uma função (normalmente uma arrow function fn(…) => …) e a aplicam a cada item. Juntas, substituem a maioria dos foreach que "montam um array novo".

array_map: transformar cada item

<?php
$precos = [10.0, 25.5, 4.0];
$comAumento = array_map(fn($p) => $p * 1.1, $precos);
print_r($comAumento);
echo "Os preços originais: ", implode(", ", $precos), "\n";
$nomes = ["ana", "bruno", "carla"];
echo implode(", ", array_map(fn($n) => ucfirst($n), $nomes)), "\n";
echo implode(", ", array_map("strtoupper", $nomes)), "\n";

"Mapeie": aplique uma função a cada item e devolva um array novo com os resultados.
fn($p) => $p * 1.1

"strtoupper"

array_reduce: reduzir a um valor só

<?php
$notas = [9.5, 6.0, 8.5, 5.5, 7.0];
$soma = array_reduce($notas, fn($total, $n) => $total + $n, 0);
echo "Soma: $soma\n";
echo "Soma: ", array_sum($notas), "\n";
echo "Média: ", array_sum($notas) / count($notas), "\n";
echo "Maior: ", max($notas), " / Menor: ", min($notas), "\n";
echo "Produto: ", array_product([2, 3, 4]), "\n";
echo array_sum([]), "\n";

O array_reduce passa por todos os itens carregando um "acumulado". A função recebe o acumulado até ali ($total) e o item da vez ($n), e devolve o novo acumulado. O último argumento (0) é o valor inicial. Volta a volta: 0 + 9.5 = 9.5; 9.5 + 6 = 15.5; … até 36.5.

$ php f-reduce.php

Soma: 36.5              « array_sum faz o mesmo, pronto
Média: 7.3
Maior: 9.5 / Menor: 5.5
Produto: 24             « 2 × 3 × 4
0                       « soma de um array vazio: 0

Para somas, prefira array_sum; para maior e menor, max e min. O array_reduce fica para contas que não têm função pronta.

<?php

range é prático com foreach (foreach (range(1, 12) as $mes)) e para montar listas de opções, como os anos num formulário.

Quando dá errado

"A função não fez nada"

O que aconteceu: você chamou uma função que devolve um array novo (array_filter, array_map, array_unique, array_slice, array_merge…) e não guardou o resultado. Não há erro nem aviso: o resultado simplesmente se perde, como no exemplo f-ref3.php do começo da aula.

Como resolver: $fila = array_filter($fila, …);.

O array virou um número 
<?php
$fila = ["Ana", "Bruno"];
$fila = array_push($fila, "Carla");
var_dump($fila);

$ php f-ref2.php
int(3)

O que aconteceu: o erro oposto. array_push já muda $fila e devolve o novo tamanho (3). Guardar esse retorno em $fila joga a lista fora. O mesmo acontece com sort, que devolve true (aula Ordenar Arrays).

Como resolver: chame só array_push($fila, "Carla");, sem atribuição.

Argument #1 ($array) could not be passed by reference 
<?php
$ultimo = array_pop(["a", "b"]);

$ php f-ref.php

Fatal error: Uncaught Error: array_pop(): Argument #1 ($array) could not be passed by reference in /home/ana/site/f-ref.php:2
Stack trace:
#0 {main}
  thrown in /home/ana/site/f-ref.php on line 2

O que aconteceu: as funções que mudam o array precisam de uma variável para mudar. Um array escrito direto ali (ou o resultado de outra função) não é uma variável: não há onde guardar a mudança.

Como resolver: guarde numa variável antes: $letras = ["a", "b"]; $ultimo = array_pop($letras);. Se você só quer o último valor, sem tirá-lo, use array_last (8.5).

array_search "não achou" o primeiro item

O que aconteceu: o item estava na posição 0, e if (!array_search(…)) trata 0 como falso. Veja a saída de f-search.php, mais acima: Não achei arroz?!.

Como resolver: compare com !== false. O mesmo vale para array_find_key e array_key_first, que podem devolver 0.

Missão final

Missão: sem escrever nenhum foreach, mostre (1) os nomes dos alunos com nota 7 ou mais, separados por vírgula: Aprovados: Ana, Carla, Elisa; e (2) a média da turma: Média: 7.3. Use array_filter para escolher os aprovados e array_column para pegar os nomes e as notas.

<?php
$alunos = [
    ["nome" => "Ana",   "nota" => 9.5],
    ["nome" => "Bruno", "nota" => 6.0],
    ["nome" => "Carla", "nota" => 8.5],
    ["nome" => "Diego", "nota" => 5.5],
    ["nome" => "Elisa", "nota" => 7.0],
];

$aprovados = $alunos; // troque por um array_filter
echo "Aprovados: ", "?", "\n";
echo "Média: ", "?", "\n";

<?php
$alunos = [
    ["nome" => "Ana",   "nota" => 9.5],
    ["nome" => "Bruno", "nota" => 6.0],
    ["nome" => "Carla", "nota" => 8.5],
    ["nome" => "Diego", "nota" => 5.5],
    ["nome" => "Elisa", "nota" => 7.0],
];

$aprovados = array_filter($alunos, fn($a) => $a["nota"] >= 7);
echo "Aprovados: ", implode(", ", array_column($aprovados, "nome")), "\n";
echo "Média: ", array_sum(array_column($alunos, "nota")) / count($alunos), "\n";

$ php turma.php
Aprovados: Ana, Carla, Elisa
Média: 7.3

Resumo

  • Saiba se a função devolve um array novo (guarde o resultado) ou muda o array (só chame).
  • in_array e array_search comparam com ==; passe true para o modo estrito. Teste o array_search com !== false.
  • array_merge junta e renumera (nomes: vence a direita); + junta por chave (vence a esquerda).
  • array_slice copia um pedaço; array_splice tira e insere no próprio array.
  • push/pop no fim, unshift/shift no começo.
  • array_map transforma, array_filter escolhe (mantém chaves), array_reduce resume.
  • PHP 8.4: array_find, array_any, array_all. PHP 8.5: array_first, array_last.
