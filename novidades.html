PHP Novidades do 8.0 ao 8.5

O PHP lança uma versão nova por ano, sempre em novembro. Do 8.0 (2020) ao 8.5 (2025), a linguagem mudou muito: ganhou match, enums, propriedades somente-leitura, o operador pipe… Esta página é um mapa: o que cada versão trouxe, um exemplo curto de cada recurso rodado de verdade no PHP 8.5 do laboratório, a aula do guia onde ele é explicado, e o que foi removido ou ficou obsoleto pelo caminho.

Você vai aprender
  • Os recursos mais importantes de cada versão, do 8.0 ao 8.5.
  • Como reconhecer, num código, a versão mínima de PHP que ele exige.
  • O que foi removido (e dá erro) e o que está obsoleto (e dá aviso Deprecated).
  • A modernizar um trecho de código antigo.

Não precisa decorar nada daqui. Use como consulta quando encontrar um código ou tutorial e quiser saber "isso funciona no meu PHP?". Para ver a versão instalada: php -v (veja Versões do PHP).

clone($objeto, [...])
Copia o objeto já trocando algumas propriedades. É o jeito de "mudar" objetos readonly: você não muda, cria uma cópia alterada. Com propriedades readonly, o clone com mudanças precisa ser feito dentro da classe (como no método comY), porque readonly só permite gravar de dentro (veja o erro abaixo).
array_first / array_last
O primeiro e o último valor do array, sem mexer no ponteiro interno (diferente de reset/end) e sem depender de as chaves serem 0, 1, 2… Array vazio dá null.
Uri\Rfc3986\Uri
Analisa endereços seguindo a norma RFC 3986, com um método para cada parte. Substitui com vantagens o antigo parse_url(), que aceita muita coisa errada.
Uri\WhatWg\Url
Analisa endereços do jeito que os navegadores fazem (norma WHATWG), normalizando-os.

O que saiu: removido e obsoleto

Duas palavras importantes:

  • Obsoleto (deprecated): ainda funciona, mas mostra um aviso Deprecated: … e vai ser removido numa versão futura. É o momento de trocar.
  • Removido: não existe mais; dá erro.

Propriedades dinâmicas (obsoletas desde o 8.2)

Antes, dava para criar uma propriedade em qualquer objeto só atribuindo: $c->idade = 30;, mesmo sem $idade declarada na classe. Isso escondia erros de digitação ($c->nmoe = "Ana" criava uma propriedade nova em vez de reclamar). Desde o 8.2, avisa, como você viu acima:

Deprecated: Creation of dynamic property Cliente::$idade is deprecated in /home/ana/nov/v82.php on line 17

Conserto: declare a propriedade na classe (public int $idade;). Se a classe realmente precisa disso, marque-a com #[\AllowDynamicProperties]. Objetos stdClass (os de json_decode, por exemplo) continuam aceitando sem aviso:

<?php
#[\AllowDynamicProperties]
class Ficha {}
$f = new Ficha();
$f->qualquer = 1;
echo "sem aviso: $f->qualquer\n";
$o = new stdClass();
$o->nome = "Ana";
echo "stdClass: $o->nome\n";

Quando dá errado

Parse error num código copiado de um tutorial

O que significa: o código usa um recurso mais novo que o seu PHP (por exemplo, |> num PHP 8.4, ou enum num PHP 8.0).

Como consertar: php -v, procure o recurso nesta página e atualize o PHP, ou reescreva com a forma antiga.

Call to undefined function array_find() (ou json_validate, array_first…)

O que significa: a função é mais nova que o seu PHP: array_find é do 8.4; array_first, do 8.5; json_validate, do 8.3.

Como consertar: atualize o PHP. Se não der, escreva o equivalente com foreach, ou instale um pacote "polyfill" com o Composer (como o symfony/polyfill-php84), que cria essas funções em versões antigas.

Uma tela cheia de Deprecated depois de atualizar o PHP

O que significa: o código usa recursos marcados como obsoletos na versão nova. Ele ainda funciona.

Como consertar: leia cada aviso (ele quase sempre diz o que usar), troque usando a tabela acima e não esconda os avisos: na próxima versão, eles viram erros.

Missão final: modernize esta classe escrita no estilo do PHP 7: (1) use a promoção no construtor com tipos (private string $cliente, private string $status) e apague as propriedades e atribuições repetidas; (2) troque o switch por match; (3) declare o retorno : string. A saída não deve mudar.

<?php
class Pedido
{
    private $cliente;
    private $status;

    public function __construct($cliente, $status)
    {
        $this->cliente = $cliente;
        $this->status = $status;
    }

    public function descricao()
    {
        switch ($this->status) {
            case 'pago':
                $texto = 'Pago';
                break;
            case 'enviado':
                $texto = 'A caminho';
                break;
            default:
                $texto = 'Aguardando pagamento';
        }
        return $this->cliente . ': ' . $texto;
    }
}

foreach ([new Pedido('Bruno', 'pago'), new Pedido('Carla', 'novo')] as $p) {
    echo $p->descricao(), "\n";
}

<?php
class Pedido
{
    public function __construct(
        private string $cliente,
        private string $status,
    ) {}

    public function descricao(): string
    {
        $texto = match ($this->status) {
            'pago' => 'Pago',
            'enviado' => 'A caminho',
            default => 'Aguardando pagamento',
        };
        return "$this->cliente: $texto";
    }
}

foreach ([new Pedido('Bruno', 'pago'), new Pedido('Carla', 'novo')] as $p) {
    echo $p->descricao(), "\n";
}

Resumo

  • 8.0: match, argumentos nomeados, ?->, promoção no construtor, union types, atributos, str_contains.
  • 8.1: enums, readonly, fibers, strlen(...), never, array_is_list.
