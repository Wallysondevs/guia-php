PHP Funções Anônimas e Arrow Functions

Até aqui, toda função tinha um nome: function soma(…). Em PHP você também pode criar uma função sem nome e guardá-la numa variável, como se fosse um número ou um texto. Isso parece estranho até você ver para que serve: entregar um "pedaço de comportamento" para outra função usar, como "dobre cada preço" ou "fique só com as notas acima de 7".

Você vai aprender
  • O que é uma função anônima (closure) e como guardá-la numa variável e chamá-la.
  • Por que ela não enxerga as variáveis de fora, e como trazê-las com use ($x) e use (&$x).
  • As arrow functions fn($x) => $x * 2, curtas e com captura automática.
  • Como passar funções como argumento para array_map e array_filter, e como receber uma função com o tipo callable.
  • Os erros mais comuns, com as mensagens reais do PHP.

Esta aula usa funções, arrays e o que você viu em Escopo (uma função não enxerga as variáveis de fora). Os exemplos rodam na máquina da Ana, na pasta ~/site.

A ideia antes do código: o bilhete com instruções

A Ana vai viajar e deixa a lojinha com o Bruno. Ela não sabe ainda quais produtos vão chegar, mas sabe o que fazer com cada um: "cole uma etiqueta com o preço em dobro". Ela escreve essa instrução num bilhete e entrega ao Bruno. O Bruno não precisa saber de onde veio a regra: ele pega cada produto e aplica o que está no bilhete.

Uma função anônima é esse bilhete: um conjunto de instruções que você guarda e entrega para outra parte do programa executar quando precisar. O PHP tem funções prontas (como array_map, o "Bruno") que recebem esse bilhete e o aplicam a cada item de um array.

Função anônima: uma função guardada numa variável

<?php
$dobro = function ($x) {
    return $x * 2;
};

echo $dobro(5), "\n";
echo $dobro(21), "\n";

Uma variável comum, que vai guardar a função.
function ($x)
A palavra function sem nome logo depois: por isso "anônima". O resto é igual a uma função normal: parâmetros entre parênteses…
{ return $x * 2; }
…e o corpo entre chaves.
;
O ponto e vírgula depois da } é obrigatório. A linha inteira é uma atribuição ($dobro = …;), e toda atribuição termina com ;. Numa função com nome, não há ; depois da chave.
$dobro(5)
Para chamar, use a variável seguida de parênteses com os argumentos.
$ php anonima.php

Por isso as funções anônimas também são chamadas de closures (o nome da classe; em inglês, closure é "fechamento", porque a função pode "fechar" variáveis de fora dentro dela, como você vai ver no use). O nome que o PHP inventa para ela, {closure:arquivo:linha}, aparece nas mensagens de erro PHP 8.4+; nas versões antigas aparecia só {closure}.

Experimente: rode e depois crie uma função anônima $triplo logo abaixo da $dobro e mostre $triplo(7). Tente também echo $dobro($dobro(3)); (a função usada duas vezes).

$dobro = function ($x) {
    return $x * 2;
};

echo $dobro(21), "\n";

Passar uma função para outra: array_map

Guardar uma função numa variável só fica útil quando você a entrega a alguém. O exemplo mais comum é array_map ("mapear o array"): ele recebe uma função e um array, chama a função para cada elemento e devolve um array novo com os resultados.

<?php
$precos = [10, 25, 4.5];

$dobrados = array_map(function ($p) {
    return $p * 2;
}, $precos);

print_r($dobrados);
array_map(
A função pronta do PHP. O primeiro argumento é a função a aplicar; o segundo, o array.
function ($p) { return $p * 2; }
A função anônima, escrita direto no lugar do argumento, sem guardar numa variável. O array_map vai chamá-la três vezes: com 10, com 25 e com 4.5.
, $precos)
O array original. Ele não muda: o resultado vem num array novo, guardado em $dobrados.
$ php map.php

    [1] => 50
    [2] => 9

O mesmo resultado com um foreach exigiria criar o array vazio, percorrer e acrescentar. Com array_map, você diz só o que fazer com cada item. Funções de array que recebem outras funções aparecem muito: array_map (transformar), array_filter (filtrar, mais abaixo), usort (ordenar com uma regra sua, veja Ordenar Arrays).

Funções com nome também podem ser entregues

No lugar da função anônima, você pode passar o nome de uma função existente, entre aspas: array_map('ucfirst', ["ana", "bruno"]) devolve ["Ana", "Bruno"]. Tudo o que pode ser chamado assim (uma closure, o nome de uma função…) se chama callable ("chamável"). A forma moderna de fazer isso, ucfirst(...), está em Callables de Primeira Classe.

A closure não enxerga as variáveis de fora

A Ana quer acrescentar uma taxa de 10% em cada preço. A taxa está numa variável, fora da função:

<?php
$taxa = 0.1;

$comTaxa = function ($preco) {
    return $preco + $preco * $taxa;
};

echo $comTaxa(50), "\n";

$ php semuse.php

Warning: Undefined variable $taxa in /home/ana/site/semuse.php on line 5
50                      « a taxa valeu null, e 50 + 50 × null = 50

"Variável indefinida $taxa". Como qualquer função (veja Escopo), a closure tem o seu próprio "mundo" de variáveis: o $taxa lá de fora não existe aqui dentro. O PHP avisa, usa null no lugar e o programa continua com o resultado errado.

use ($taxa): levar uma cópia para dentro

A palavra use ("usar"), escrita depois dos parâmetros, diz quais variáveis de fora a closure deve levar junto:

<?php
$taxa = 0.1;

$comTaxa = function ($preco) use ($taxa) {
    return $preco + $preco * $taxa;
};

echo $comTaxa(50), "\n";

$taxa = 0.5;
echo $comTaxa(50), "\n";
function ($preco)
O parâmetro: o valor que muda a cada chamada.
use ($taxa)
A variável de fora que a closure leva. Várias, separadas por vírgula: use ($taxa, $frete).

Repare na segunda linha. O use copia o valor da variável no momento em que a closure é criada (a linha 4), como tirar uma foto. Mudar $taxa depois não altera a foto que a closure guardou.

use (&$total): mexer na variável de fora

Como o use leva uma cópia, mudar a variável dentro da closure também não afeta a de fora. Quando você precisa disso (um contador, um total acumulado), coloque & antes do nome: a closure passa a usar a própria variável, e não uma cópia. Isso se chama passagem por referência.

<?php
$total = 0;

$somar = function ($valor) use ($total) {
    $total += $valor;
};
$somar(10);
$somar(5);
echo "Sem &: $total\n";

$somarDeVerdade = function ($valor) use (&$total) {
    $total += $valor;
};
$somarDeVerdade(10);
$somarDeVerdade(5);
echo "Com &: $total\n";

$ php useref.php
Sem &: 0         « cada chamada somou na sua cópia, que foi jogada fora
Com &: 15        « a closure mexeu no $total de verdade
FormaO que a closure recebeMudanças de fora, depois de criadaMudanças de dentro
use ($x)Uma cópia do valor (a "foto")Não aparecem dentroNão saem para fora
use (&$x)A própria variávelAparecem dentroSaem para fora
Use o & com moderação

Uma closure que muda variáveis de fora é mais difícil de entender: quem lê o código precisa procurar onde ela é chamada para saber o valor final. Quando der, prefira que a função devolva um valor com return e você mesmo o guarde. O mesmo conselho vale para o global, que você viu em Escopo.

Arrow functions: fn($x) => …

Funções anônimas pequenas, de uma linha só, são tão comuns que o PHP 7.4 criou uma forma curta: a arrow function ("função seta", por causa do =>).

<?php
$dobro = fn($x) => $x * 2;
echo $dobro(5), "\n";

$taxa = 0.1;
$comTaxa = fn($preco) => $preco + $preco * $taxa;
echo $comTaxa(50), "\n";

$precos = [10, 25, 4.5];
print_r(array_map(fn($p) => $p * 2, $precos));
fn
Abreviação de function.
($x)
Os parâmetros, como sempre.
=>
A "seta": separa os parâmetros do resultado.
$x * 2
Uma única expressão, que é devolvida automaticamente. Não se escreve return, nem chaves.
$ php arrow.php
10
55                « a arrow function enxergou $taxa sozinha, sem use
Array
(
    [0] => 20
    [1] => 50
    [2] => 9
)

A grande vantagem aparece na segunda função: não precisou de use. A arrow function captura automaticamente, por valor, todas as variáveis de fora que ela usa. É como se o PHP escrevesse o use ($taxa) por você. Compare as duas versões do mesmo código:

<?php
// função anônima: return, chaves, ponto e vírgula e use
$comTaxa = function ($preco) use ($taxa) {
    return $preco + $preco * $taxa;
};

// arrow function: uma linha
$comTaxa = fn($preco) => $preco + $preco * $taxa;

Os limites da arrow function

Como a captura é por valor (uma cópia), uma arrow function não consegue mudar variáveis de fora:

<?php
$contador = 0;
$somaUm = fn() => $contador++;
$somaUm();
$somaUm();
echo "contador = $contador\n";

$ php arrowmuda.php
contador = 0       « cada chamada aumentou uma cópia

E ela só aceita uma expressão. Se precisar de várias linhas (um if, uma variável auxiliar, um foreach), use a função anônima completa. Tentar abrir chaves depois da seta dá erro de sintaxe (veja Quando dá errado).

Filtrar com array_filter

array_filter ("filtrar o array") recebe um array e uma função que responde true ou false para cada elemento. Ficam só os elementos com true. A Ana quer saber quem passou de ano:

<?php
$notas = ["Ana" => 9.5, "Bruno" => 5.0, "Carla" => 8.5, "Diego" => 6.0];

$aprovados = array_filter($notas, fn($nota) => $nota >= 7);
print_r($aprovados);

$minima = 6;
$recuperacao = array_filter($notas, fn($nota) => $nota < 7 && $nota >= $minima);
print_r($recuperacao);

$ php filtrar.php
Array
(
    [Ana] => 9.5
    [Carla] => 8.5
)
Array
(
    [Diego] => 6
)

Repare na ordem dos argumentos: array_filter($array, $funcao), ao contrário de array_map($funcao, $array). É uma confusão famosa do PHP; na dúvida, consulte Funções de Array. E repare que as chaves (os nomes) foram mantidas.

Experimente: mude a nota mínima de aprovação para 8.5 e veja quem sobra. Depois crie $nomes = array_map(fn($n) => strtoupper($n), array_keys($aprovados)); e mostre os nomes em maiúsculas com print_r.

<?php
$notas = ["Ana" => 9.5, "Bruno" => 5.0, "Carla" => 8.5, "Diego" => 6.0];

$aprovados = array_filter($notas, fn($nota) => $nota >= 7);
print_r($aprovados);

Outras formas de usar funções como valores

Guardar funções num array

Funções são valores; então podem ficar dentro de um array. Uma calculadora sem nenhum if:

<?php
$operacoes = [
    "+" => fn($a, $b) => $a + $b,
    "-" => fn($a, $b) => $a - $b,
    "*" => fn($a, $b) => $a * $b,
    "/" => fn($a, $b) => $a / $b,
];

foreach ($operacoes as $sinal => $conta) {
    echo "12 $sinal 4 = ", $conta(12, 4), "\n";
}

echo $operacoes["*"](6, 7), "\n";

$ php calculadora.php
12 + 4 = 16
12 - 4 = 8
12 * 4 = 48
12 / 4 = 3
42

$operacoes["*"] é a função de multiplicar; (6, 7) logo depois a chama. Você vai usar essa ideia no projeto da calculadora.

Receber uma função: o tipo callable

Você também pode escrever as suas próprias funções que recebem funções. O tipo callable garante que o argumento pode ser chamado:

<?php
function aplicarEmTodos(array $lista, callable $funcao): array
{
    $resultado = [];
    foreach ($lista as $item) {
        $resultado[] = $funcao($item);
    }
    return $resultado;
}

$precos = [10, 25, 4.5];
print_r(aplicarEmTodos($precos, fn($p) => $p * 2));
print_r(aplicarEmTodos(["ana", "bruno"], 'strtoupper'));
print_r(aplicarEmTodos($precos, "dobrar"));

Uma função que devolve uma função

<?php
function multiplicador(int $vezes): Closure
{
    return fn($x) => $x * $vezes;
}

$dobro = multiplicador(2);
$triplo = multiplicador(3);
echo $dobro(10), " ", $triplo(10), "\n";

$ php fabrica.php
20 30

multiplicador é uma "fábrica de funções": cada chamada cria uma arrow function que guardou o seu próprio $vezes. É a captura por valor trabalhando a seu favor.

Resumo

  • Uma função anônima (closure) é uma função sem nome, guardada numa variável: $f = function ($x) { … }; (com ; no fim). Chame com $f(…).
  • Ela não enxerga variáveis de fora. use ($x) leva uma cópia do valor no momento da criação; use (&$x) leva a própria variável.
  • A arrow function fn($x) => expressão é a forma curta: uma expressão, return automático e captura automática por valor.
  • Funções são valores: podem ser passadas para array_map, array_filter, usort, guardadas em arrays e devolvidas por outras funções. O tipo do parâmetro é callable (ou Closure).
  • Erros comuns: Undefined variable (faltou use), unexpected token (faltou ; ou chaves numa arrow function), could not be converted to string (faltaram os parênteses).
