Entrada fixa (data-stdin) e várias abas

<?php
require 'funcoes.php';
echo "Nome: ";
$nome = trim(fgets(STDIN));
echo "Idade: ";
$idade = (int) fgets(STDIN);
echo frase($nome, $idade), "\n";

<?php
function frase(string $n, int $i): string {
    return "$n tem $i ano";
}

<?php
function frase(string $n, int $i): string {
    return "$n tem $i anos";
}

Modo web com formulário e sessão

Missão: rode, escreva "Bia" no formulário e envie.

<?php
session_start();
$_SESSION['visitas'] = ($_SESSION['visitas'] ?? 0) + 1;
$nome = $_POST['nome'] ?? '';
?>
<!DOCTYPE html>
<html lang="pt-BR">
<head><meta charset="utf-8"><title>Saudação</title></head>
<body>
<?php if ($nome !== ''): ?>
  <h1>Olá, <?= htmlspecialchars($nome) ?>!</h1>
<?php endif; ?>
<p>Visitas nesta sessão: <?= $_SESSION['visitas'] ?></p>
<form method="post">
  <input name="nome" placeholder="Seu nome"> <button>Enviar</button>
</form>
<p><a href="?pagina=2">Um link com GET</a> · <a href="sair.php">Sair (redireciona)</a></p>
<?php if (isset($_GET['pagina'])) echo "<p>Página " . (int) $_GET['pagina'] . "</p>"; ?>
</body>
</html>
