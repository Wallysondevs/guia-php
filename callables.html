PHP Callables de Primeira Classe

Muitas funções do PHP recebem outra função como argumento: array_map aplica uma função a cada item, usort usa uma função para comparar, array_filter usa uma para decidir quem fica. Algo que pode ser chamado como função é um callable ("chamável"). O PHP tem várias formas de escrever um callable; a mais moderna, do PHP 8.1, é a mais curta e a mais segura: strlen(...).

Você vai aprender
  • O que é um callable e por que passar uma função como valor.
  • As formas antigas: 'strlen', [$objeto, 'metodo'], 'Classe::metodo', e os problemas delas.
  • call_user_func, is_callable e o tipo callable.
  • Closure::fromCallable().
  • A sintaxe de callable de primeira classe: strlen(...), $objeto->metodo(...), Classe::metodo(...). PHP 8.1+
  • A usar tudo isso com array_map, array_filter e usort.

Antes, veja Funções Anônimas e Arrow Functions: lá você criou funções novas para passar adiante (fn($x) => $x * 2). Aqui o assunto é passar funções e métodos que já existem.

A ideia: passar a receita, não o bolo

Quando a Ana pede ao Bruno "faça um bolo", o Bruno entrega o bolo pronto. Mas, se ela pede "use esta receita em cada um destes 10 ingredientes", ela entrega a receita, e o Bruno a aplica quantas vezes precisar.

Em PHP, strlen("caneca") é o bolo: a função roda e devolve 6. Para o array_map, a Ana precisa entregar a receita, a própria função strlen, sem rodá-la. A dúvida é: como escrever "a função strlen" sem chamá-la? É isso que esta aula responde.

As formas antigas: texto e array

Durante muitos anos, o PHP aceitou como callable um texto com o nome da função, ou um array com o objeto e o nome do método:

<?php
class Loja
{
    public function __construct(private float $taxa) {}

    public function comTaxa(float $preco): float
    {
        return round($preco * (1 + $this->taxa), 2);
    }

    public static function formatar(float $valor): string
    {
        return "R$ " . number_format($valor, 2, ",", ".");
    }
}

$precos = [10, 19.9, 49.9];
$loja = new Loja(0.1);

// 1. string com o nome de uma função
print_r(array_map('round', $precos));

// 2. array [objeto, 'método']
print_r(array_map([$loja, 'comTaxa'], $precos));

// 3. array ['Classe', 'método estático'] ou string 'Classe::método'
print_r(array_map(['Loja', 'formatar'], $precos));
print_r(array_map('Loja::formatar', $precos));

// chamando direto a partir de uma variável
$f = 'strtoupper';
echo $f("caneca"), "\n";
$g = [$loja, 'comTaxa'];
echo $g(100), "\n";
echo call_user_func('str_repeat', "ab", 3), "\n";

Para o PHP, 'strlenn' é só um texto. Ninguém confere se a função existe até o array_map tentar usá-la:

print_r(array_map('strlenn', $nomes));

Aqui o erro ficou perto, mas, se o texto tivesse sido guardado numa variável no começo do programa e usado bem depois, o erro apontaria para a linha do uso.

Problema 2: os editores não enxergam

Para o editor (veja Editores e IDEs), 'comTaxa' é um texto qualquer. Se você usar "Renomear método" para trocar comTaxa por aplicarTaxa, o texto não muda e o programa quebra. "Ir para a definição" e "Encontrar usos" também não funcionam.

is_callable e o tipo callable

Para saber se um valor pode ser chamado, existe is_callable():

<?php
class Loja
{
    public function publico() {}
    private function privado() {}
}
$loja = new Loja();
var_dump(is_callable('strlen'));
var_dump(is_callable('strlenn'));
var_dump(is_callable([$loja, 'publico']));
var_dump(is_callable([$loja, 'privado']));
var_dump(is_callable(fn() => 1));

$ php iscall.php

bool(false)          « a função não existe
bool(true)
bool(false)          « existe, mas é privada (vista de fora)
bool(true)           « funções anônimas também são callables

E, para exigir um callable num parâmetro, use o tipo callable:

<?php
function aplicarATodos(array $itens, callable $acao): array
{
    $resultado = [];
    foreach ($itens as $item) {
        $resultado[] = $acao($item);
    }
    return $resultado;
}

print_r(aplicarATodos(["ana", "bruno"], ucfirst(...)));
print_r(aplicarATodos(["ana", "bruno"], 'strtoupper'));
print_r(aplicarATodos(["ana", "bruno"], fn($n) => "Olá, $n"));
print_r(aplicarATodos(["ana"], "nao_existe"));

As três formas foram aceitas; o texto "nao_existe", não. (O ucfirst(...) da primeira chamada é a forma nova, explicada daqui a pouco.) O tipo callable só pode ser usado em parâmetros e retornos, não em propriedades de classe; para guardar numa propriedade, use o tipo Closure.

Nunca use texto vindo do usuário como callable

Como qualquer nome de função vira callable, $acao = $_GET['acao']; $acao($dados); deixa o visitante escolher qual função do PHP rodar (unlink, system…). Se precisar escolher uma ação pelo nome, use uma lista fechada: $acoes = ['maiuscula' => strtoupper(...), …]; e confira com isset($acoes[$nome]).

Closure::fromCallable()

O PHP 7.1 trouxe um meio-termo: transformar qualquer callable num objeto Closure (o mesmo tipo das funções anônimas). A conferência acontece na hora da conversão:

<?php
class Loja
{
    public function __construct(private float $taxa) {}
    public function comTaxa(float $preco): float { return round($preco * (1 + $this->taxa), 2); }
}
$tamanho = Closure::fromCallable('strlen');
$taxa = Closure::fromCallable([new Loja(0.1), 'comTaxa']);
var_dump($tamanho);
echo $tamanho("caneca"), "\n";
echo $taxa(100), "\n";

Métodos privados como callable

Dentro de uma classe, $this->metodo(...) cria um Closure que "lembra" que foi criado lá dentro. Ele pode ser entregue para fora e continua funcionando, mesmo com um método private:

<?php
class Carrinho
{
    private array $itens = ["caneca", "camiseta", "boné"];

    private function capitalizar(string $s): string
    {
        return ucfirst($s);
    }

    public function nomes(): array
    {
        return array_map($this->capitalizar(...), $this->itens);
    }

    public function nomesAntigo(): array
    {
        return array_map([$this, 'capitalizar'], $this->itens);
    }

    public function entregarCallable(): Closure
    {
        return $this->capitalizar(...);
    }
}
$c = new Carrinho();
print_r($c->nomes());
print_r($c->nomesAntigo());
$f = $c->entregarCallable();
echo $f("bolsa"), "\n";
print_r(array_map([$c, 'capitalizar'], ["x"]));

Na prática: array_map, array_filter, usort

A Ana recebeu uma lista de produtos digitada às pressas, com espaços sobrando, maiúsculas misturadas e itens vazios. Com funções que já existem no PHP, ela limpa tudo sem escrever nenhuma função nova:

<?php
$entrada = ["  caneca ", "CAMISETA", " boné", "12", "", "chaveiro  "];

$limpos = array_map(trim(...), $entrada);
$semVazios = array_filter($limpos, strlen(...));
$minusculos = array_map(mb_strtolower(...), $semVazios);
usort($minusculos, strcmp(...));

print_r($minusculos);
echo implode(", ", array_map(ucfirst(...), $minusculos)), "\n";
LinhaO que faz
array_map(trim(...), $entrada)Aplica trim (tira os espaços das pontas) a cada item
array_filter($limpos, strlen(...))Mantém os itens em que strlen dá algo "verdadeiro" (diferente de 0): some o texto vazio. Repare na ordem: no array_filter, o callable vem depois do array
array_map(mb_strtolower(...), …)Tudo em minúsculas, inclusive letras acentuadas (veja mbstring)
usort($minusculos, strcmp(...))Ordena usando strcmp para comparar dois textos (veja Ordenar Arrays)
array_map(ucfirst(...), …)Primeira letra maiúscula, para mostrar
$ php uso.php
Array
(
    [0] => 12
    [1] => boné
    [2] => camiseta
    [3] => caneca
    [4] => chaveiro
)
12, Boné, Camiseta, Caneca, Chaveiro

O "12" ficou em primeiro porque, na comparação de textos do strcmp, dígitos vêm antes das letras. Repare também que array_map(ucfirst(...), …) cabe numa linha, enquanto a versão com função anônima seria array_map(fn($s) => ucfirst($s), …). Quando a função já existe e recebe exatamente um argumento, o callable de primeira classe é a escrita mais limpa. Na próxima aula, o operador pipe |> usa essa mesma sintaxe para encadear transformações da esquerda para a direita.

Cuidado com funções de vários parâmetros

O array_map passa um argumento por item. array_map(round(...), $precos) funciona porque o segundo parâmetro de round é opcional. Para arredondar com 1 casa, você precisa fixar o segundo argumento, e aí entra a arrow function: array_map(fn($p) => round($p, 1), $precos).

Quando dá errado

must be a valid callback or null, function "strlenn" not found

O que significa: um callable em forma de texto tem um nome que não existe.

Como consertar: corrija o nome. Melhor ainda: troque por strlen(...), e o próximo erro de digitação vai aparecer na hora, como Call to undefined function.

cannot access private method Carrinho::capitalizar()

O que significa: o callable [$objeto, 'metodo'] aponta para um método privado e foi usado de fora da classe.

Como consertar: se a classe quer oferecer esse comportamento, ela entrega um $this->metodo(...) por um método público; senão, torne o método público.

Cannot combine nullsafe operator with Closure creation 
$ php nullsafe.php       « $f = $loja?->comTaxa(...);

Fatal error: Cannot combine nullsafe operator with Closure creation in /home/ana/call/nullsafe.php on line 3
Stack trace:
#0 {main}

O que significa: ?-> (veja ?? e ?->) e (...) não combinam: se $loja fosse null, não haveria método para embrulhar.

Como consertar: confira o null antes: $f = $loja !== null ? $loja->comTaxa(...) : null;.

Cannot create Closure for new expression 
$ php novo.php           « $f = new DateTime(...);

Fatal error: Cannot create Closure for new expression in /home/ana/call/novo.php on line 2
Stack trace:
#0 {main}

O que significa: new Classe(...) não vira callable.

Como consertar: use uma arrow function: fn(string $d) => new DateTime($d).

Resumo

  • Callable = algo que pode ser chamado: função, método, função anônima. Serve para passar uma "receita" a array_map, array_filter, usort…
  • Formas antigas: 'strlen', [$obj, 'metodo'], 'Classe::metodo'. Funcionam, mas o erro aparece tarde e o editor não as entende.
  • PHP 8.1+ strlen(...), $obj->metodo(...), Classe::metodo(...) criam um Closure: conferido na hora, visível para o editor, com a visibilidade de onde foi criado.
  • is_callable() testa; callable é o tipo de parâmetro; Closure, o de propriedade.
  • Função já pronta, com um argumento: (...). Precisa fixar argumentos ou combinar: arrow function.
