PHP Glossário

Os termos que aparecem no guia, em ordem alfabética, explicados em uma ou duas frases. Cada um tem o link para a aula em que é explicado com calma. Termos em inglês aparecem com a tradução; quando o nome em inglês é o mais usado (como closure ou trait), ele é a entrada principal.

Dica

Use Ctrl+F no navegador para achar um termo, ou o índice de letras abaixo. Para funções específicas, veja também as referências de funções de string, de funções de array e de mensagens de erro.

A · B · C · D · E · F · G · H · I · J · L · M · N · O · P · R · S · T · U · V · X

A

API
Um "cardápio" de endereços que outro programa pode chamar para pedir ou enviar dados, em vez de uma página para pessoas. Na web, as APIs costumam responder em JSON. Veja: Criar uma API JSON e Consumir APIs.
Argumento
O valor que você entrega a uma função quando a chama: em strlen("Ana"), o argumento é "Ana". Do lado de dentro da função, ele chega num parâmetro. Veja: Funções.
Argumentos nomeados PHP 8.0+
Passar argumentos pelo nome do parâmetro, em qualquer ordem: number_format(1234.5, decimals: 2). Permite pular parâmetros opcionais. Veja: Parâmetros.
Array
Uma variável que guarda vários valores, cada um com uma chave: $frutas = ['maçã', 'banana']. No PHP, o mesmo tipo serve de lista e de "dicionário". Veja: Arrays Indexados.
Array associativo
Array em que as chaves são textos escolhidos por você: ['nome' => 'Ana', 'idade' => 29]. É como uma ficha com campos nomeados. Veja: Arrays Associativos.
Array indexado
Array cujas chaves são os números 0, 1, 2…, criados automaticamente na ordem em que os valores entram. Veja: Arrays Indexados.
Array multidimensional
Array que contém outros arrays, como uma tabela (linhas e colunas): $alunos[0]['nome']. Veja: Arrays Multidimensionais.
Arrow function (função seta)
Forma curta de função anônima com uma expressão só: fn($x) => $x * 2. Enxerga sozinha as variáveis de fora. Veja: Funções Anônimas e Arrow Functions.
Atribuição
Guardar um valor numa variável com =. Os atalhos +=, .=, ??= etc. fazem a conta e guardam de uma vez. Veja: Operadores de Atribuição.
Atributo PHP 8.0+
Uma etiqueta com informação extra presa a uma classe, método ou função, escrita com #[…], como #[\Override] e #[\NoDiscard]. Veja: Atributos.
Autoload (carregamento automático)
Mecanismo que carrega o arquivo de uma classe sozinho, na primeira vez que ela é usada, sem um require para cada arquivo. É feito com spl_autoload_register ou pelo Composer. Veja: Autoload e PSR-4.
Aviso (Warning)
Mensagem do PHP sobre algo errado que não para o programa, como Warning: Undefined array key "a". O script continua, muitas vezes com um valor errado. Veja: Tipos de Erro.

B

Banco de dados
Programa (ou arquivo) que guarda dados em tabelas e permite buscá-los e alterá-los com SQL. No guia: SQLite e MySQL/MariaDB. Veja: Banco de Dados: o Básico.
bcrypt
O algoritmo de hash de senhas que o password_hash usa por padrão; os hashes começam com $2y$. É lento de propósito, para dificultar quem tenta adivinhar senhas. Veja: Senhas.
Booleano (bool)
Tipo com só dois valores: true (verdadeiro) e false (falso). É o resultado de toda comparação. Veja: Booleanos.
break e continue
break (quebrar) sai do laço na hora; continue (continuar) pula para a próxima volta. Veja: break e continue.

C

Cabeçalho HTTP (header)
Informações que vão antes do conteúdo de uma resposta, como Location (redirecionar) e Set-Cookie. O PHP envia com header(), sempre antes de imprimir qualquer coisa. Veja: header e Redirecionamento.
Callable (chamável)
Qualquer coisa que pode ser chamada como função: o nome de uma função em texto, uma closure, [$objeto, 'metodo']. Funções como array_map recebem callables. Veja: Callables de Primeira Classe.
Callable de primeira classe PHP 8.1+
A sintaxe strlen(...) (com três pontos) que transforma uma função ou método num objeto Closure sem chamá-lo. Veja: Callables de Primeira Classe.
Classe
O "molde" de um tipo de objeto: diz que dados (propriedades) e que ações (métodos) cada objeto daquele tipo tem. class Produto { … }. Veja: Classes e Objetos.
Classe abstrata
Classe marcada com abstract: não pode virar objeto direto, só servir de base para outras, que completam os métodos abstratos. Veja: Classes Abstratas.
CLI (linha de comando)
Rodar o PHP no terminal, como php script.php, em vez de num servidor web. A saída vai para o terminal, e os erros aparecem como texto. Veja: PHP na Linha de Comando.
Closure (função anônima)
Uma função sem nome, guardada numa variável ou passada como argumento: function ($x) use ($taxa) { … }. O use traz variáveis de fora. Veja: Funções Anônimas e Arrow Functions.
Comentário
Texto no código que o PHP ignora, para explicar o código a quem lê: // uma linha, # uma linha e /* várias */. Veja: Comentários.
Composer
O gerenciador de pacotes do PHP: baixa bibliotecas de outras pessoas (do Packagist), anota as versões no composer.json/composer.lock e gera o autoload em vendor/autoload.php. Veja: Composer.
Concatenação
Juntar textos com o operador ponto: "Olá, " . $nome. Veja: Operadores de String.
Constante
Um nome para um valor que não muda, criado com const ou define: const TAXA = 0.05;. Usada sem $. Veja: Constantes.
Construtor
O método __construct, chamado automaticamente no new, que prepara o objeto. Com a "promoção de propriedades", os parâmetros viram propriedades direto. Veja: Construtores.
Conversão de tipos
Transformar um valor de um tipo em outro: de propósito, com (int), (float), (string); ou automática, quando o PHP faz isso sozinho numa conta ou comparação ("10" + 5 é 15). Veja: Conversão de Tipos.
Cookie
Um pequeno texto que o site pede para o navegador guardar e devolver a cada visita. O PHP cria com setcookie() e lê em $_COOKIE. Fica no computador do visitante, que pode alterá-lo. Veja: Cookies.
CRUD
Sigla para as quatro operações básicas com dados: Create (criar, INSERT), Read (ler, SELECT), Update (atualizar, UPDATE) e Delete (apagar, DELETE). Veja: CRUD com PDO e o projeto Tarefas.
CSRF
Cross-Site Request Forgery (falsificação de pedido entre sites): outro site faz o navegador da vítima enviar um formulário para o seu, aproveitando o cookie de sessão dela. A defesa é um token secreto em cada formulário. Veja: CSRF e Segurança de Formulários.
CSV
"Valores separados por vírgula": formato de planilha em texto puro, uma linha por registro. O PHP lê e escreve com fgetcsv/fputcsv. Veja: CSV.

D

declare(strict_types=1)
Primeira linha de um arquivo que liga a tipagem estrita: os tipos dos parâmetros passam a ser conferidos sem conversão automática ("5" não é aceito onde se pede int). Veja: Tipos e Retorno.
Depurar (debug)
Procurar e consertar um erro no programa: ler a mensagem, olhar os valores com var_dump, usar um depurador como o Xdebug. Veja: Depurar.
Deprecated (obsoleto)
Aviso de que um recurso ainda funciona, mas vai mudar ou sumir numa versão futura, como Deprecated: fputcsv(): the $escape parameter must be provided…. Veja: Tipos de Erro.
Desestruturação
Tirar os valores de um array direto para variáveis: [$nome, $idade] = $pessoa; ou ['nome' => $n] = $ficha;. Veja: Desestruturação (list).

E

echo e print
Os comandos que mostram texto. echo ("ecoar") aceita vários valores separados por vírgula; <?= … ?> é o atalho de echo dentro do HTML. Veja: echo e print.
Enum (enumeração) PHP 8.1+
Um tipo com uma lista fechada de valores possíveis: enum Status { case Pendente; case Pago; }. Evita textos soltos como 'pago' espalhados pelo código. Veja: Enums.
Erro fatal (Fatal error)
Erro que para o programa na hora, como Fatal error: Uncaught TypeError ou Call to undefined function. Veja: Tipos de Erro e Lendo Erros do PHP.
Escapar
Transformar caracteres especiais para que sejam tratados como texto comum: htmlspecialchars escapa para HTML (< vira &lt;); \" escapa uma aspa dentro de string. Veja: Escapar a Saída (XSS).
Escopo
A região do código em que uma variável existe. Variáveis de dentro de uma função não enxergam as de fora (e vice-versa), a não ser com parâmetros, global ou use. Veja: Escopo.
Exceção
Um objeto que representa um erro e é "lançado" com throw. Se ninguém o pegar com try/catch, vira Fatal error: Uncaught …. Veja: Exceções (try e catch) e Criar suas Exceções.
Expressão
Qualquer pedaço de código que produz um valor: 2 + 3, $idade >= 18, strlen($nome), um match. Veja: Sintaxe.

F

float
Número com casas decimais (3.14), escrito sempre com ponto no código. Contas com float podem ter pequenos erros: 0.1 + 0.2 == 0.3 é false. Veja: int e float.
for
Laço com contador: for ($i = 1; $i <= 10; $i++). Bom quando você sabe quantas voltas quer. Veja: for.
foreach
Laço que passa por cada item de um array: foreach ($precos as $produto => $preco). É o laço mais usado no PHP. Veja: foreach.
Formulário
A parte da página (<form>) com campos que o usuário preenche e envia ao servidor, por GET ou POST. Veja: Formulários HTML.
Função
Um bloco de código com nome, que recebe parâmetros, faz um trabalho e pode devolver um valor com return. Escreve-se uma vez e usa-se quantas vezes quiser. Veja: Funções.
Função anônima
Veja Closure.
Função variádica
Função que aceita qualquer quantidade de argumentos, recebidos num array com ...: function somar(int ...$numeros). Veja: Funções Variádicas.

G

GET
O método HTTP de "buscar": é o que o navegador usa ao abrir um endereço ou seguir um link. Os dados vão no endereço (?busca=pão) e chegam em $_GET. Não deve ser usado para mudar dados. Veja: $_GET e $_POST.
$GLOBALS
Superglobal com todas as variáveis globais do script, acessíveis de dentro de funções. Funciona, mas deixa o código difícil de seguir: prefira parâmetros. Veja: Escopo.

H

Hash (de senha)
Resultado de uma conta de mão única: da senha se chega ao hash, mas do hash não se volta à senha. O banco guarda o hash (password_hash) e o login confere com password_verify. Veja: Senhas.
Heredoc e nowdoc
Formas de escrever textos de várias linhas: heredoc (<<<FIM) troca as variáveis como as aspas duplas; nowdoc (<<<'FIM') não troca nada, como as aspas simples. Veja: Heredoc e Nowdoc.
Herança
Uma classe que "estende" outra (class Livro extends Produto) recebe as propriedades e os métodos dela e pode mudá-los ou acrescentar novos. Veja: Herança.
htmlspecialchars
A função que escapa < > & " ' antes de pôr um texto na página, impedindo XSS. Todo texto vindo do usuário deve passar por ela na saída. Veja: Escapar a Saída.
HTTP
O "idioma" que navegador e servidor usam: o navegador manda um pedido (método, endereço, cabeçalhos, corpo) e o servidor devolve uma resposta (código como 200 ou 404, cabeçalhos, conteúdo). Veja: Como o PHP Funciona.

I

include e require
Trazem o código de outro arquivo para o atual. Se o arquivo faltar, include só avisa e require para tudo; as versões _once não incluem o mesmo arquivo duas vezes. Veja: include e require.
Instância
Outro nome para objeto: "uma instância da classe Produto" é um objeto criado com new Produto(…). Veja: Classes e Objetos.
int
Número inteiro, sem casas decimais: 42, -7. Veja: int e float.
Interface
Um "contrato": lista métodos que uma classe promete ter (class Pix implements Pagamento), sem dizer como. Permite tratar classes diferentes do mesmo jeito. Veja: Interfaces.
Interpolação
Pôr variáveis direto dentro de um texto entre aspas duplas: "Olá, $nome", "Total: {$pedido['total']}". Aspas simples não interpolam. Veja: Interpolação.
isset
"Está definido?": devolve true se a variável ou a chave existe e não é null. Muito usado com $_GET, $_POST e $_SESSION. Veja: null.

J

JSON
Formato de texto para trocar dados entre programas, parecido com os arrays do PHP: {"nome": "Ana", "idade": 29}. O PHP converte com json_encode e json_decode. Veja: JSON.

L

Laço (loop)
Código que se repete enquanto uma condição for verdadeira ou para cada item de uma lista: while, do-while, for, foreach. Veja: while e do-while.

M

match PHP 8.0+
Expressão que escolhe um valor comparando com ===: $texto = match ($nota) { 10 => 'ótimo', default => 'ok' };. Sem braço para o valor, dá UnhandledMatchError. Veja: match.
mbstring
As funções mb_* (mb_strlen, mb_strtoupper…), que contam e mexem em letras, e não em bytes, e por isso funcionam com acentos em UTF-8. Veja: Acentos e mbstring.
Método
Uma função que pertence a uma classe e age sobre o objeto: $carrinho->adicionar($produto). Dentro dele, $this é o próprio objeto. Veja: Propriedades e Métodos.
Métodos mágicos
Métodos com nomes começando por __ que o PHP chama sozinho em certas situações: __construct, __toString, __get… Veja: Métodos Mágicos.
MySQL e MariaDB
Bancos de dados servidores, muito usados em sites PHP. O PDO conversa com eles quase do mesmo jeito que com o SQLite; muda a conexão. Veja: MySQL e MariaDB.

N

Namespace (espaço de nomes)
Um "sobrenome" para classes e funções (namespace Loja\Pagamentos;), que evita conflito entre nomes iguais de bibliotecas diferentes. Usa-se use para importar. Veja: Namespaces.
never PHP 8.1+
Tipo de retorno de uma função que nunca volta: ela sempre termina o script (exit) ou lança uma exceção. Veja: Tipos Avançados.
null
O valor "nada": uma variável sem valor. É o que uma função sem return devolve. Veja: null.
Null coalescing (??)
"Se não existir (ou for null), use este outro": $_GET['nome'] ?? 'visitante'. Não dá aviso de chave inexistente. Veja: ?? e ?->.
Nullsafe (?->) PHP 8.0+
Chama um método ou lê uma propriedade só se o objeto não for null; se for, o resultado todo é null: $pedido?->cliente?->nome. Veja: ?? e ?->.

O

Objeto
Um "exemplar" criado a partir de uma classe com new, com os seus próprios valores: $p = new Produto('Café', 18.5);. Veja: Classes e Objetos.
Operador
Símbolo que faz uma operação com valores: aritméticos (+ - * / % **), de comparação (== === < >), lógicos (&& || !), de texto (.). Veja: Operadores Aritméticos e Precedência.
Operador pipe (|>) PHP 8.5+
Passa o valor da esquerda para a função da direita, encadeando passos da esquerda para a direita: $texto |> trim(...) |> strtoupper(...). Veja: Operador Pipe.
Operador ternário
Um if/else numa expressão: $idade >= 18 ? 'adulto' : 'menor'. Veja: Operador Ternário.

P

Packagist
O site (packagist.org) onde ficam os pacotes que o Composer instala. Veja: Composer.
Parâmetro
A variável, na definição da função, que recebe um argumento: em function saudar($nome), $nome é o parâmetro. Pode ter tipo e valor padrão. Veja: Parâmetros.
PDO
PHP Data Objects: o jeito padrão de conversar com bancos de dados no PHP, igual para SQLite, MySQL e outros. Veja: Conectar com PDO.
PHP
Linguagem de programação feita para a web: roda no servidor, gera o HTML que o navegador recebe e também roda no terminal. O nome hoje significa PHP: Hypertext Preprocessor. Veja: O que é PHP.
php -S
O servidor web embutido no PHP, para desenvolver: php -S localhost:8000 serve a pasta atual. Não é para colocar sites no ar. Veja: O Servidor Embutido.
php.ini
O arquivo de configuração do PHP: mostrar erros, fuso horário, tamanho máximo de upload… php --ini mostra onde ele está. Veja: Instalar no Linux.
PHPUnit
A ferramenta de testes automatizados mais usada no PHP: você escreve testes que conferem se o seu código dá os resultados esperados. Veja: Testes com PHPUnit.
POO (programação orientada a objetos)
Forma de organizar o programa em classes e objetos que juntam dados e comportamento. Veja: O que é POO.
POST
O método HTTP de "enviar": usado por formulários method="post". Os dados vão no corpo do pedido (não aparecem no endereço) e chegam em $_POST. É o método certo para ações que mudam dados. Veja: $_GET e $_POST.
Post/Redirect/Get (PRG)
Padrão em que, depois de processar um POST, o PHP redireciona (header('Location: …')) para uma página GET. Assim o F5 não reenvia o formulário. Veja: header e Redirecionamento e o projeto de contato.
Precedência
A ordem em que os operadores são calculados numa expressão: 2 + 3 * 4 é 14, porque * vem antes de +. Parênteses mudam a ordem. Veja: Precedência.
Prepared statement (consulta preparada)
SQL enviado ao banco com "buracos" (? ou :nome) e os valores mandados separados, com prepare + execute. Os valores nunca viram parte do comando, o que impede a injeção de SQL. Veja: Prepared Statements e SQL Injection.
Propriedade
Uma variável que pertence a um objeto: $produto->preco. Veja: Propriedades e Métodos.
Property hooks (ganchos de propriedade) PHP 8.4+
Código get e set preso a uma propriedade, que roda quando ela é lida ou alterada, sem precisar de métodos getPreco()/setPreco(). Veja: readonly e Property Hooks.
PSR
PHP Standards Recommendations: recomendações escritas pelo PHP-FIG para o código de projetos diferentes conversar bem, como a PSR-4 (autoload) e as regras de estilo de código. Veja: Padrões PSR.
PSR-4
A regra que liga namespaces a pastas: a classe Loja\Produto fica em src/Produto.php. É o que permite o autoload do Composer. Veja: Autoload e PSR-4.

R

readonly PHP 8.1+
Propriedade que só pode receber valor uma vez (normalmente no construtor); depois disso, tentar mudar dá erro. Desde o 8.2 existe a classe inteira readonly. Veja: readonly e Property Hooks.
Recursão
Uma função que chama a si mesma, resolvendo um problema grande com versões menores dele mesmo, até um caso simples que para. Veja: Recursão.
Redirecionamento
Resposta que manda o navegador ir para outro endereço, com um código 3xx e o cabeçalho Location. No PHP: header('Location: pagina.php'); exit;. Veja: header e Redirecionamento.
$_REQUEST
Superglobal que junta $_GET, $_POST (e, conforme a configuração, $_COOKIE). Como não diz de onde veio cada valor, prefira as específicas. Veja: $_SERVER e Outras Superglobais.
return
Termina a função e devolve um valor para quem a chamou. Veja: Tipos e Retorno.

S

Script
Um arquivo de programa que roda do começo ao fim, como um .php. Veja: Olá, Mundo.
$_SERVER
Superglobal com informações do pedido e do servidor: REQUEST_METHOD (GET ou POST), REQUEST_URI, HTTP_USER_AGENT… Veja: $_SERVER e Outras Superglobais e a referência de superglobais.
Sessão
Dados guardados no servidor para um visitante, entre uma página e outra (por exemplo, quem está logado). O navegador guarda só um cookie com o número da sessão (PHPSESSID). No PHP: session_start() e $_SESSION. Veja: Sessões e o projeto de login.
Sintaxe
As regras de escrita da linguagem: <?php, ponto e vírgula, chaves, $ nas variáveis. Um erro de sintaxe vira Parse error e nada roda. Veja: Sintaxe.
SQL
A linguagem dos bancos de dados: SELECT, INSERT, UPDATE, DELETE, CREATE TABLE. Veja: Banco de Dados: o Básico.
SQL injection (injeção de SQL)
Ataque em que um texto digitado pelo usuário vira parte do comando SQL, porque foi colado nele: id=0 OR 1=1 num DELETE apaga a tabela inteira. A defesa são os prepared statements. Veja: Prepared Statements e SQL Injection.
SQLite
Banco de dados que é um arquivo só, sem servidor para instalar. Ótimo para aprender e para sites pequenos; o PHP fala com ele pelo PDO. Veja: Conectar com PDO.
static
Numa classe, marca propriedades e métodos que pertencem à classe, não a cada objeto (Produto::$total). Numa função, uma variável static guarda o valor entre uma chamada e outra. Veja: static e Escopo.
String
Texto: uma sequência de caracteres entre aspas, 'Ana' ou "Olá, $nome". Veja: Strings e Funções de String.
Superglobal
Variável especial que o PHP cria sozinho e que existe em qualquer lugar do código: $_GET, $_POST, $_SERVER, $_FILES, $_COOKIE, $_SESSION, $_ENV, $_REQUEST e $GLOBALS. Veja: $_SERVER e Outras Superglobais.
switch
Escolhe entre vários casos comparando com ==; cada caso precisa de break, senão "cai" no seguinte. No PHP 8, o match costuma ser mais seguro. Veja: switch.

T

Tag do PHP
<?php abre o código PHP e ?> fecha; fora delas, o texto é enviado como está (HTML). <?= $x ?> é o atalho para mostrar um valor. Veja: PHP Dentro do HTML.
Tipagem (declaração de tipo)
Dizer o tipo esperado de parâmetros, retornos e propriedades: function dobro(int $n): int. O PHP confere e reclama se vier outra coisa. Veja: Tipos e Retorno.
Tipo
A "espécie" de um valor: int, float, string, bool, array, null, objetos… var_dump mostra o tipo junto com o valor. Veja: Tipos de Dados.
Token
Um código secreto e aleatório (bin2hex(random_bytes(32))) usado para provar que um pedido é legítimo, como o token CSRF escondido nos formulários. Veja: CSRF.
Trait
Um pacote de métodos que pode ser "colado" em várias classes com use NomeDoTrait;, para reaproveitar código sem herança. Veja: Traits.
try / catch
"Tente / pegue": o código que pode lançar uma exceção vai no try; o catch trata o erro em vez de deixar o programa parar; o finally roda sempre. Veja: Exceções.
TypeError
Erro lançado quando um valor do tipo errado chega onde um tipo foi exigido, como trim(): Argument #1 ($string) must be of type string, array given. Veja: Tipos e Retorno.

U

Union type (tipo união) PHP 8.0+
Um tipo que aceita mais de uma opção: int|float, string|null (o mesmo que ?string). Veja: Tipos Avançados.
Upload
Enviar um arquivo pelo formulário (enctype="multipart/form-data" e <input type="file">). O PHP recebe em $_FILES e o arquivo é guardado com move_uploaded_file. Veja: Upload de Arquivos.
UTF-8
A codificação de texto usada na web, que representa qualquer letra do mundo. Letras acentuadas ocupam 2 bytes, por isso strlen('é') é 2 e mb_strlen('é') é 1. Veja: Acentos e mbstring.

V

Validação
Conferir, no servidor, se o que o usuário enviou faz sentido (campo preenchido, e-mail válido, número no intervalo) antes de usar. A checagem do HTML ajuda, mas pode ser pulada. Veja: Validar Dados.
var_dump e print_r
Funções para "ver por dentro" de uma variável: var_dump mostra tipo e valor (string(3) "Ana"); print_r mostra arrays de forma mais curta. Veja: var_dump e print_r.
Variável
Um nome que guarda um valor, sempre começando com $: $nome = "Ana";. O valor pode mudar ao longo do programa. Veja: Variáveis.
Visibilidade
Quem pode usar uma propriedade ou método: public (todos), protected (a classe e as filhas), private (só a própria classe). Veja: Visibilidade.

X

XSS
Cross-Site Scripting: ataque em que um texto enviado por alguém (um comentário, um nome) contém HTML ou JavaScript e é mostrado na página sem escapar, rodando no navegador de outras pessoas. A defesa é htmlspecialchars em toda saída. Veja: Escapar a Saída (XSS).
